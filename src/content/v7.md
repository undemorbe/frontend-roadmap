Props передают данные **вниз**. Но как кнопке внутри карточки сообщить родителю «меня нажали, удали эту станцию»? Для этого компоненты **генерируют события** (emit). А чтобы родитель мог передать потомку не данные, а **разметку** — существуют **слоты**.

## События компонента

Потомок объявляет, какие события он генерирует, и вызывает `emit`:

```js
const StationCard = {
  props: { id: Number, name: String },
  emits: ['remove'],                 // список событий — как документация
  setup(props, { emit }) {
    function onRemove() {
      emit('remove', props.id)       // имя события и данные
    }
    return { onRemove }
  },
  template: `
    <article>
      {{ name }}
      <button @click="onRemove">Удалить</button>
    </article>`,
}
```

Родитель слушает событие так же, как событие DOM:

```html
<station-card
  v-for="s in stations" :key="s.id"
  :id="s.id" :name="s.name"
  @remove="removeStation"
></station-card>
```

```js
function removeStation(id) {
  stations.value = stations.value.filter((s) => s.id !== id)
}
```

Данные текут вниз через props, события всплывают вверх через emit — так у каждого состояния один владелец, и ясно, кто его меняет.

> [!tip] Совет
> В шаблоне можно вызывать `$emit` напрямую: `<button @click="$emit('remove', id)">`. Для простых случаев это удобно.

## v-model на компоненте

`v-model` работает и с компонентами. Запись

```html
<search-box v-model="query"></search-box>
```

разворачивается в

```html
<search-box :model-value="query" @update:model-value="query = $event"></search-box>
```

Значит, компонент должен принимать проп `modelValue` и генерировать событие `update:modelValue`:

```html preview vue
<div id="app">
  <rating-stars v-model="rating"></rating-stars>
  <p>Оценка: {{ rating }}</p>
</div>

<script>
  const { createApp, ref } = Vue
  const RatingStars = {
    props: { modelValue: { type: Number, default: 0 } },
    emits: ['update:modelValue'],
    template: `
      <div>
        <button v-for="n in 5" :key="n" @click="$emit('update:modelValue', n)"
          style="font-size:24px;border:0;background:none;cursor:pointer">
          {{ n <= modelValue ? '★' : '☆' }}
        </button>
      </div>`,
  }
  createApp({ components: { RatingStars }, setup: () => ({ rating: ref(3) }) }).mount('#app')
</script>
```

В `<script setup>` (следующая станция) для этого есть макрос `defineModel()`, который сокращает код до одной строки.

## Слоты

Слот — «дырка» в шаблоне компонента, куда родитель вставляет свою разметку. Это как `children` у HTML-элементов: `<button>` не знает, что внутри него — текст или иконка.

```js
const InfoCard = {
  template: `
    <section class="card">
      <slot></slot>
    </section>`,
}
```

```html
<info-card>
  <h3>Станция «Теги»</h3>
  <p>Любой HTML <b>внутри</b>.</p>
</info-card>
```

### Содержимое по умолчанию

```html
<button class="btn"><slot>Отправить</slot></button>
```

Если родитель ничего не передал, отобразится «Отправить».

### Именованные слоты

```js
const Layout = {
  template: `
    <header><slot name="header"></slot></header>
    <main><slot></slot></main>
    <footer><slot name="footer">© Фронтенд-метро</slot></footer>`,
}
```

```html
<page-layout>
  <template #header>
    <h1>Схема линий</h1>
  </template>

  <p>Основное содержимое попадёт в слот по умолчанию.</p>

  <template #footer>Контакты</template>
</page-layout>
```

`#header` — сокращение для `v-slot:header`.

### Слоты с параметрами (scoped slots)

Иногда разметку определяет родитель, а данные есть только у потомка. Тогда потомок передаёт данные **в слот**:

```html preview vue
<div id="app">
  <station-list :items="stations">
    <template #item="{ station, index }">
      <b>{{ index + 1 }}.</b> {{ station.name }} <small v-if="station.new">— новая!</small>
    </template>
  </station-list>
</div>

<script>
  const { createApp } = Vue
  const StationList = {
    props: ['items'],
    template: `
      <ul>
        <li v-for="(s, i) in items" :key="s.id">
          <slot name="item" :station="s" :index="i">{{ s.name }}</slot>
        </li>
      </ul>`,
  }
  createApp({
    components: { StationList },
    setup: () => ({ stations: [{ id: 1, name: 'Pinia', new: true }, { id: 2, name: 'Vue Router' }] }),
  }).mount('#app')
</script>
```

Список отвечает за структуру (`ul`/`li`, перебор), а родитель — за то, как выглядит каждый пункт. На этом приёме построены таблицы и списки в UI-библиотеках.
