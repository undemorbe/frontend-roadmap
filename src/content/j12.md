Когда кода становится много, держать его в одном файле невозможно. **Модули** позволяют разбить программу на файлы, каждый из которых явно говорит, что он отдаёт наружу (`export`) и что берёт у других (`import`). Это пересадочная станция: на ES-модулях построены Vite и Vue.

## export и import

```js
// math.js
export const PI = 3.14159
export function sum(a, b) {
  return a + b
}

// main.js
import { PI, sum } from './math.js'
console.log(sum(PI, 1))
```

Именованный экспорт можно переименовать при импорте и импортировать всё сразу:

```js
import { sum as add } from './math.js'
import * as math from './math.js'   // math.sum, math.PI
```

## Экспорт по умолчанию

Модуль может иметь **один** экспорт по умолчанию — «главное», что он отдаёт:

```js
// formatPrice.js
export default function formatPrice(n) {
  return `${n.toLocaleString('ru-RU')} ₽`
}

// main.js
import formatPrice from './formatPrice.js'  // без фигурных скобок, имя — любое
```

Во Vue каждый компонент `.vue` экспортирует себя по умолчанию: `import TodoItem from './TodoItem.vue'`.

> [!tip] Совет
> Многие команды предпочитают **именованные** экспорты: их проще находить поиском и автоматически импортировать в редакторе. `default` оставляют для «одной главной вещи» — компонента, конфига.

## Особенности модулей

- **Своя область видимости.** Переменные модуля не попадают в глобальную область — нет конфликтов имён.
- **Строгий режим** всегда включён.
- **Выполняются один раз.** Сколько бы раз модуль ни импортировали, его код выполнится единожды, а все получат одни и те же экспорты. Это используют для общих хранилищ (как в Pinia).
- **Отложенное выполнение**, как у `defer`.
- `import` — только на верхнем уровне файла, путь — строка-литерал.

В браузере модуль подключают с `type="module"`:

```html
<script type="module" src="main.js"></script>
```

## Динамический импорт

`import()` как функция загружает модуль **по требованию** и возвращает промис:

```js
button.addEventListener('click', async () => {
  const { openEditor } = await import('./editor.js')  // загрузится только при клике
  openEditor()
})
```

Сборщики (Vite) превращают каждый динамический импорт в отдельный файл — так большое приложение грузится по частям. Во Vue Router так делают «ленивые» страницы.

## Пакеты из npm

Импорт без `./` в начале — это **пакет** из `node_modules`:

```js
import { createApp } from 'vue'
import dayjs from 'dayjs'
```

Браузер сам не знает, где искать `'vue'`, — это задача сборщика (Vite) или import map. Об этом — на линии «Инструменты».

> [!info] Как это связано
> Практика этой станции работает на настоящих ES-модулях: каждый файл в редакторе — отдельный модуль, точка входа — `main.js`.
