Формы — главный способ получить данные от пользователя: регистрация, поиск, заказ, комментарий. Хорошая форма — это половина удобства сайта.

## Тег form

```html
<form action="/subscribe" method="post">
  <!-- поля -->
  <button type="submit">Подписаться</button>
</form>
```

- `action` — адрес, куда отправить данные;
- `method` — `get` (данные попадут в URL, подходит для поиска) или `post` (в теле запроса — для всего остального).

При нажатии на кнопку `submit` браузер соберёт данные всех полей с атрибутом `name` и отправит их. В современных приложениях отправку часто перехватывают JavaScript'ом — об этом на станции «События».

## Поля ввода input

`<input>` — одиночный тег, его поведение задаёт атрибут `type`:

```html preview
<form>
  <p><input type="text" placeholder="Текст"></p>
  <p><input type="email" placeholder="email@example.com"></p>
  <p><input type="password" placeholder="Пароль"></p>
  <p><input type="number" min="1" max="10" value="3"></p>
  <p><input type="date"></p>
  <p><input type="range" min="0" max="100"></p>
  <p><input type="color" value="#2167c9"></p>
  <p><label><input type="checkbox" checked> Флажок</label></p>
  <p>
    <label><input type="radio" name="size" value="s"> S</label>
    <label><input type="radio" name="size" value="m" checked> M</label>
  </p>
  <p><input type="file"></p>
</form>
```

Правильный `type` важен: на телефоне `email` покажет клавиатуру с `@`, `tel` — цифровую, а `date` — календарь.

Радиокнопки с **одинаковым `name`** образуют группу: выбрать можно только одну.

## Подписи: label

У каждого поля должна быть подпись `<label>`. Она связывается с полем двумя способами:

```html
<!-- 1. Через for и id -->
<label for="email">Электронная почта</label>
<input type="email" id="email" name="email">

<!-- 2. Обёрткой -->
<label>
  <input type="checkbox" name="agree"> Согласен с правилами
</label>
```

Связь даёт две вещи: клик по подписи ставит фокус в поле (попасть по маленькому чекбоксу проще!), а скринридер зачитывает подпись вместе с полем.

> [!warn] Осторожно
> `placeholder` — не замена `label`. Он исчезает, когда пользователь начинает печатать, и часто плохо контрастен.

## Другие элементы форм

```html preview
<form>
  <p>
    <label for="city">Город</label>
    <select id="city" name="city">
      <option value="">— выберите —</option>
      <option value="msk">Москва</option>
      <option value="spb" selected>Санкт-Петербург</option>
    </select>
  </p>
  <p>
    <label for="msg">Сообщение</label><br>
    <textarea id="msg" name="message" rows="3" cols="30"></textarea>
  </p>
  <fieldset>
    <legend>Способ связи</legend>
    <label><input type="radio" name="contact" value="tg"> Telegram</label>
    <label><input type="radio" name="contact" value="mail"> Почта</label>
  </fieldset>
  <button type="submit">Отправить</button>
  <button type="reset">Очистить</button>
</form>
```

- `<select>` + `<option>` — выпадающий список;
- `<textarea>` — многострочный текст (парный тег!);
- `<fieldset>` + `<legend>` — группа полей с общим заголовком (особенно важно для радиокнопок);
- `<button>` по умолчанию внутри формы имеет `type="submit"`. Для кнопок, которые не должны отправлять форму, пишите `type="button"`.

## Встроенная валидация

Браузер умеет проверять поля сам — без JavaScript:

| Атрибут | Что проверяет |
|---|---|
| `required` | Поле обязательно |
| `type="email"`, `type="url"` | Формат адреса |
| `minlength`, `maxlength` | Длина текста |
| `min`, `max`, `step` | Диапазон чисел и дат |
| `pattern="[0-9]{6}"` | Регулярное выражение |

```html preview
<form>
  <label for="zip">Индекс (6 цифр)</label>
  <input id="zip" name="zip" required pattern="[0-9]{6}" placeholder="190000">
  <button>Проверить</button>
</form>
```

Нажмите «Проверить» с пустым или неверным полем — браузер покажет подсказку и не отправит форму.

Полезные атрибуты удобства: `autocomplete="email"` (браузер подставит сохранённое значение), `inputmode="numeric"` (цифровая клавиатура), `autofocus`.

> [!info] Как это связано
> На станции «События» линии JavaScript вы будете перехватывать отправку этой же формы и проверять поля кодом. А во Vue поля связываются с данными через `v-model`.
