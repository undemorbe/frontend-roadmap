Пересадка на жёлтую линию. HTML описывает, CSS оформляет, а **JavaScript** заставляет страницу *действовать*: реагировать на клики, проверять формы, загружать данные, менять содержимое без перезагрузки. Это полноценный язык программирования — и единственный, который браузер понимает «из коробки».

## Где выполняется JavaScript

- **В браузере** — управляет страницей (на этой линии).
- **На сервере и в терминале** через Node.js — на нём работают npm и Vite (линия 4).

Подключение к странице — тегом `<script>`:

```html
<!-- внешний файл: так правильно -->
<script src="script.js" defer></script>

<!-- или код прямо в HTML -->
<script>
  console.log('Привет!')
</script>
```

Атрибут `defer` говорит: «скачай скрипт параллельно, а выполни после того, как HTML разобран». Тогда скрипт можно ставить в `<head>`, и он всё равно «увидит» все элементы. Без `defer` скрипт ставят в конец `<body>`. Модули (`type="module"`) ведут себя как `defer` автоматически.

## Консоль — ваш главный друг

`console.log()` выводит значения в консоль разработчика (DevTools → Console). Это основной способ понять, что происходит в коде.

```js preview
console.log('Привет, JavaScript!')
console.log(2 + 2)
console.log('Сумма:', 10 + 5)
console.error('Так выглядит ошибка')
```

В практике этой линии консоль встроена прямо в редактор — она справа.

## Инструкции и комментарии

Программа — последовательность **инструкций**, выполняемых сверху вниз. Инструкции разделяют точкой с запятой или переносом строки. На этой схеме мы пишем без точек с запятой — так принято во Vue-экосистеме (и так настроен Prettier в шаблоне Vite). Оба стиля корректны; главное — единообразие.

```js
// однострочный комментарий

/*
  многострочный
  комментарий
*/
```

## Переменные: let и const

Переменная — именованная «коробка» для значения.

```js
let age = 25        // можно перезаписать
age = 26

const name = 'Аня'  // константа: перезаписать нельзя
// name = 'Оля'     // TypeError: Assignment to constant variable
```

**Правило:** по умолчанию пишите `const`. Если значение действительно будет меняться (счётчик, накопитель) — `let`.

> [!warn] Осторожно
> В старом коде встречается `var`. Не используйте его: у `var` странная область видимости (функция, а не блок) и «всплытие». `let` и `const` появились в 2015 году (ES6) как замена.

## Имена переменных

- Буквы, цифры, `$` и `_`; не начинаются с цифры.
- Регистр важен: `user` и `User` — разные переменные.
- Стиль **camelCase**: `userName`, `totalPrice`, `isLoggedIn`.
- Константы-«настройки», известные до запуска, иногда пишут `UPPER_SNAKE_CASE`: `const MAX_ITEMS = 50`.
- Имя должно объяснять содержимое: `cartItems`, а не `a` или `data2`.

Зарезервированные слова (`let`, `class`, `return`, `function`…) именами быть не могут.

## Строгий режим

Директива `'use strict'` в начале файла включает современное поведение языка и превращает тихие ошибки в явные. Внутри модулей и классов строгий режим включён всегда — поэтому в современном коде (и во Vue/Vite) писать её не нужно.

## Взаимодействие с пользователем (по-старому)

Встроенные окна `alert('текст')`, `prompt('Вопрос?')`, `confirm('Уверены?')` блокируют страницу и выглядят по-разному в браузерах. Для обучения сойдут, в реальных интерфейсах их заменяют своими модальными окнами.
