Формы — главный способ получить данные от пользователя. На станции «Формы» линии HTML вы размечали поля, на станции «События» линии JS — читали `input.value` вручную. Во Vue есть директива **`v-model`**, которая связывает поле и данные в обе стороны.

## Двусторонняя привязка

```html
<input v-model="name">
```

— это сокращение для:

```html
<input :value="name" @input="name = $event.target.value">
```

Данные меняются → поле обновляется. Пользователь печатает → данные обновляются.

```html preview vue
<div id="app">
  <input v-model="name" placeholder="Ваше имя">
  <p>Привет, {{ name || 'незнакомец' }}!</p>
  <p>Символов: {{ name.length }}</p>
</div>

<script>
  const { createApp, ref } = Vue
  createApp({ setup: () => ({ name: ref('') }) }).mount('#app')
</script>
```

## Разные типы полей

`v-model` сам выбирает нужное свойство и событие для каждого типа поля:

```html
<!-- текст и многострочный текст -->
<input v-model="title">
<textarea v-model="comment"></textarea>

<!-- один чекбокс → boolean -->
<input type="checkbox" v-model="agree">

<!-- несколько чекбоксов с одним массивом → массив выбранных value -->
<input type="checkbox" value="html" v-model="lines">
<input type="checkbox" value="css" v-model="lines">

<!-- радиокнопки → value выбранной -->
<input type="radio" value="day" v-model="time">
<input type="radio" value="night" v-model="time">

<!-- выпадающий список -->
<select v-model="station">
  <option disabled value="">Выберите станцию</option>
  <option v-for="s in stations" :key="s" :value="s">{{ s }}</option>
</select>
```

```html preview vue
<div id="app">
  <p>Какие линии изучаете?</p>
  <label v-for="l in all" :key="l"><input type="checkbox" :value="l" v-model="chosen"> {{ l }}</label>
  <p>Время:
    <label><input type="radio" value="утро" v-model="time"> утро</label>
    <label><input type="radio" value="вечер" v-model="time"> вечер</label>
  </p>
  <pre>{{ { chosen, time } }}</pre>
</div>

<script>
  const { createApp, ref } = Vue
  createApp({
    setup() {
      return { all: ['HTML', 'CSS', 'JS', 'Vue'], chosen: ref(['HTML']), time: ref('утро') }
    },
  }).mount('#app')
</script>
```

## Модификаторы v-model

| Модификатор | Что делает |
|---|---|
| `v-model.trim` | Убирает пробелы по краям |
| `v-model.number` | Превращает строку в число (из `input` всегда приходит строка!) |
| `v-model.lazy` | Обновляет по событию `change` (после ухода с поля), а не при каждом символе |

```html
<input v-model.trim="name">
<input type="number" v-model.number="age">
```

## Отправка формы

Форму отправляют через событие `submit` с модификатором `.prevent`, чтобы страница не перезагружалась:

```html
<form @submit.prevent="save">
  <input v-model.trim="title" required>
  <button :disabled="!title">Сохранить</button>
</form>
```

```js
const title = ref('')
const list = ref([])

function save() {
  list.value.push({ id: Date.now(), title: title.value })
  title.value = ''   // очистили поле после отправки
}
```

Данные формы удобно хранить одним `reactive`-объектом:

```js
const form = reactive({ name: '', email: '', agree: false })
const isValid = computed(() => form.name.length >= 2 && form.email.includes('@') && form.agree)
```

> [!tip] Совет
> Не забывайте про доступность: у каждого поля — `<label>`, у кнопки — понятный текст, ошибки — рядом с полем. Валидация на клиенте — для удобства, сервер всё равно должен проверять данные.
