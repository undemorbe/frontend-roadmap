Больше половины посещений сайтов — с телефонов. Адаптивная вёрстка (responsive design) — это когда одна страница удобно выглядит на любом экране: от 320px до 4K.

## Три кита адаптивности

1. **Мета-тег viewport** в `<head>` — без него телефон покажет «уменьшенную десктопную» версию:
   ```html
   <meta name="viewport" content="width=device-width, initial-scale=1">
   ```
2. **Гибкие размеры**: `%`, `fr`, `max-width`, `minmax()`, `clamp()` вместо жёстких пикселей.
3. **Медиазапросы** — разные стили для разных условий.

## Медиазапросы

```css
.cards {
  display: grid;
  grid-template-columns: 1fr;       /* по умолчанию — одна колонка */
  gap: 16px;
}

@media (min-width: 768px) {         /* экран 768px и шире */
  .cards { grid-template-columns: repeat(2, 1fr); }
}

@media (min-width: 1200px) {
  .cards { grid-template-columns: repeat(4, 1fr); }
}
```

Стили внутри `@media` применяются, только если условие истинно. Популярные условия:

```css
@media (max-width: 600px) { }                 /* 600px и уже */
@media (min-width: 600px) and (max-width: 900px) { }
@media (width >= 768px) { }                   /* современный синтаксис диапазонов */
@media (orientation: landscape) { }
@media (hover: hover) { }                     /* устройство с мышью */
@media (prefers-color-scheme: dark) { }       /* тёмная тема ОС */
@media (prefers-reduced-motion: reduce) { }   /* пользователь просит меньше анимаций */
@media print { }                              /* при печати */
```

## Mobile first

Подход **mobile first**: сначала пишем стили для самого узкого экрана (без медиазапросов), а затем через `min-width` **добавляем** сложность для широких.

Почему так лучше:

- мобильная версия обычно проще — одна колонка, меньше кода;
- код для телефонов не перегружен переопределениями;
- заставляет думать о главном контенте.

> [!tip] Совет
> Не привязывайтесь к конкретным устройствам («iPhone 15»). Ставьте точку перелома (breakpoint) там, где **ломается ваш макет**: сужайте окно в DevTools и смотрите, когда становится тесно. Режим устройств в DevTools: <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd>.

## Адаптивность без медиазапросов

Современный CSS часто обходится без точек перелома:

```css
/* Резиновая сетка */
.grid { grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); }

/* Резиновая типографика */
h1 { font-size: clamp(1.75rem, 1rem + 4vw, 3.5rem); }

/* Резиновые отступы */
.section { padding-block: clamp(32px, 8vw, 96px); }

/* Не шире экрана */
img { max-width: 100%; height: auto; }
```

## Контейнерные запросы

Медиазапросы смотрят на ширину **окна**. Но одна и та же карточка может стоять и в узком сайдбаре, и в широком контенте. **Контейнерные запросы** смотрят на ширину **родителя**:

```css
.card-wrap { container-type: inline-size; }

.card { display: grid; gap: 12px; }

@container (min-width: 400px) {
  .card { grid-template-columns: 120px 1fr; } /* картинка слева, когда места хватает */
}
```

Компонент становится по-настоящему независимым — это особенно ценно во Vue, где компоненты переиспользуются в разных местах.

## Адаптивные изображения и видео

```css
img, video {
  max-width: 100%;
  height: auto;
  display: block;
}
.cover {
  width: 100%;
  aspect-ratio: 16 / 9;   /* пропорции без «хаков» */
  object-fit: cover;      /* заполнить, обрезав лишнее, как background-size: cover */
}
```
