Объект — коллекция пар «ключ: значение». Пользователь, товар, настройки, ответ сервера — почти любые данные в JavaScript хранятся в объектах.

## Создание и доступ к свойствам

```js
const user = {
  name: 'Аня',
  age: 25,
  'favorite color': 'зелёный',   // ключ с пробелом — в кавычках
  isAdmin: false,
}

user.name                 // 'Аня' — через точку
user['favorite color']    // через скобки — для «неудобных» ключей
const key = 'age'
user[key]                 // 25 — ключ из переменной

user.city = 'Казань'      // добавить свойство
user.age = 26             // изменить
delete user.isAdmin       // удалить
'name' in user            // true — проверка наличия
user.phone                // undefined — нет такого свойства
```

Заметьте: `user` объявлен через `const`, но менять его свойства можно. `const` запрещает **перезаписать переменную** (`user = {}`), а не изменять объект внутри неё.

Сокращения при создании:

```js
const name = 'Аня'
const age = 25
const user = { name, age }          // то же, что { name: name, age: age }
const field = 'email'
const form = { [field]: '' }        // вычисляемый ключ: { email: '' }
```

## Методы и this

Функция, лежащая в свойстве объекта, называется **методом**. Внутри метода `this` — объект, у которого метод вызван:

```js
const cart = {
  items: [],
  add(item) {                 // сокращённая запись метода
    this.items.push(item)
  },
  get count() {               // геттер — вычисляемое свойство
    return this.items.length
  },
}

cart.add('Чай')
cart.count   // 1 — без скобок
```

> [!warn] Осторожно
> `this` определяется **в момент вызова**: если передать `cart.add` как колбэк (`button.onclick = cart.add`), `this` потеряется. У стрелочных функций своего `this` нет — они берут его снаружи. Поэтому методы объектов пишут обычными функциями, а колбэки внутри методов — стрелками.

## Ссылки и копирование

Примитивы копируются **по значению**, объекты — **по ссылке**:

```js
let a = 5
let b = a
b++          // a по-прежнему 5

const user = { name: 'Аня' }
const admin = user          // та же ссылка на тот же объект!
admin.name = 'Оля'
console.log(user.name)      // 'Оля'
```

Чтобы скопировать объект:

```js
const copy = { ...user }               // поверхностная копия (spread)
const merged = { ...defaults, ...options }  // слияние: правые перезаписывают левые
const deep = structuredClone(user)     // глубокая копия (со вложенными объектами)
```

Сравнение объектов `===` сравнивает **ссылки**: `{} === {}` — `false`.

> [!info] Как это связано
> Во Vue данные нельзя «случайно» менять в дочерних компонентах (однонаправленный поток данных), а в Pinia состояние часто заменяют копией. Понимание ссылок — ключ к пониманию реактивности.

## Деструктуризация

Распаковка свойств в переменные:

```js
const user = { name: 'Аня', age: 25, address: { city: 'Казань' } }

const { name, age } = user
const { name: userName } = user            // с переименованием
const { role = 'student' } = user          // со значением по умолчанию
const { address: { city } } = user         // вложенная
const { name: n, ...rest } = user          // rest: остальные свойства

// Особенно удобно в параметрах функций:
function greet({ name, age = 18 }) {
  return `${name}, ${age}`
}
greet(user)
```

## Перебор объекта

```js preview
const prices = { tea: 120, coffee: 180, cake: 250 }

console.log(Object.keys(prices))     // ключи
console.log(Object.values(prices))   // значения
console.log(Object.entries(prices))  // пары [ключ, значение]

for (const [item, price] of Object.entries(prices)) {
  console.log(`${item}: ${price} ₽`)
}
```

## JSON — объекты в виде текста

JSON (JavaScript Object Notation) — текстовый формат для обмена данными, очень похожий на объекты JS. Ключи — только в двойных кавычках, без функций и `undefined`.

```js
const text = JSON.stringify({ name: 'Аня', age: 25 })  // '{"name":"Аня","age":25}'
const obj = JSON.parse(text)                           // обратно в объект
```

Подробнее — на станции «fetch, JSON, хранилище».
