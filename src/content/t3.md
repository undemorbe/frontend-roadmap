**Vite** (франц. «быстро») — современный инструмент сборки фронтенда от автора Vue. Он запускает dev-сервер за доли секунды, обновляет страницу при сохранении файла и собирает оптимизированный продакшен-билд. Пересадки: «Модули» (линия JS) и «SFC» (линия Vue).

## Зачем вообще сборщик

Браузер умеет ES-модули, так почему бы не писать код и сразу открывать `index.html`? Потому что в реальном проекте:

- импортируют **пакеты** из `node_modules` (`import { ref } from 'vue'`) — браузер не знает, где их искать;
- пишут на языках, которые нужно преобразовать: `.vue`-файлы, TypeScript, Sass;
- хочется мгновенно видеть изменения без ручной перезагрузки;
- в продакшене код нужно **минифицировать**, склеить, разбить на чанки и добавить хэши в имена файлов для кэширования.

Всё это делает сборщик. Раньше стандартом был Webpack, сегодня — Vite.

## Как Vite работает

- **В разработке** Vite почти ничего не собирает: отдаёт браузеру ES-модули как есть, а преобразует только то, что запрошено (например, `.vue` → JS) — поэтому старт мгновенный. Зависимости из `node_modules` один раз «предсобираются».
- **HMR** (Hot Module Replacement) — при сохранении файла обновляется только изменённый модуль, без перезагрузки страницы и с сохранением состояния.
- **В продакшене** `vite build` собирает оптимизированный бандл (используя Rolldown/Rollup).

## Создание проекта

```bash
npm create vite@latest my-app
# выбрать: Vue → JavaScript
cd my-app
npm install
npm run dev
```

Для Vue есть и официальный стартер с выбором опций (Router, Pinia, тесты, ESLint):

```bash
npm create vue@latest
```

Dev-сервер откроется на `http://localhost:5173`.

## Структура проекта

```text
my-app/
├── index.html          ← точка входа! (не в public)
├── package.json
├── vite.config.js      ← настройки Vite
├── public/             ← файлы «как есть»: favicon, robots.txt
│   └── favicon.ico
└── src/
    ├── main.js         ← JS-вход: создаёт приложение
    ├── App.vue         ← корневой компонент
    ├── style.css
    ├── assets/         ← картинки, шрифты, которые импортируются в код
    └── components/
        └── HelloWorld.vue
```

Важная особенность Vite: **`index.html` лежит в корне и является входной точкой**. В нём подключается `main.js` как модуль:

```html
<div id="app"></div>
<script type="module" src="/src/main.js"></script>
```

## Импорт не только JavaScript

Vite позволяет импортировать в JS почти что угодно:

```js
import './style.css'                   // CSS подключится на страницу
import logoUrl from './assets/logo.svg' // получим URL файла (с хэшем в продакшене)
import data from './data.json'          // JSON → объект
import App from './App.vue'             // Vue-компонент (нужен плагин)
import styles from './card.module.css'  // CSS-модули: styles.title → уникальный класс
```

## assets или public

| | `src/assets/` | `public/` |
|---|---|---|
| Как использовать | `import url from './assets/img.png'` | путь от корня: `/favicon.ico` |
| Обработка | оптимизация, хэш в имени | копируется как есть |
| Для чего | картинки компонентов, шрифты | favicon, robots.txt, файлы с фиксированным именем |

## Скрипты

```json
"scripts": {
  "dev": "vite",            // dev-сервер с HMR
  "build": "vite build",    // сборка в папку dist
  "preview": "vite preview" // локальный просмотр собранного dist
}
```
