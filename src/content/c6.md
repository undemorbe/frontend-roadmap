По умолчанию элементы выстраиваются в **нормальном потоке**: блоки сверху вниз, строчные — слева направо. Свойство `position` позволяет вытащить элемент из потока или сдвинуть его: так делают бейджи, выпадающие меню, липкие шапки и модальные окна.

## Значения position

| Значение | Поведение | Относительно чего |
|---|---|---|
| `static` | По умолчанию, обычный поток. `top/left` не работают | — |
| `relative` | Остаётся в потоке, но может быть сдвинут | своего обычного места |
| `absolute` | **Выпадает из потока** — соседи его «не видят» | ближайшего **позиционированного** предка |
| `fixed` | Выпадает из потока, приклеен к окну, не прокручивается | окна браузера |
| `sticky` | Обычный, пока не доскроллили до порога, потом «прилипает» | прокручиваемого предка |

Смещения задаются свойствами `top`, `right`, `bottom`, `left` или сокращением `inset: 0` (все четыре по нулям).

## relative + absolute: главный приём

`absolute` позиционируется относительно ближайшего предка, у которого `position` не `static`. Поэтому родителю ставят `position: relative` — он становится «точкой отсчёта»:

```html preview
<div class="card">
  <span class="badge">NEW</span>
  <h3>Курс по Vue</h3>
  <p>Бейдж прижат к правому верхнему углу карточки.</p>
</div>
<style>
  .card { position: relative; width: 260px; padding: 20px; border: 2px solid #222; border-radius: 12px; font-family: sans-serif; }
  .badge { position: absolute; top: -10px; right: 12px; background: #e4402f; color: white; padding: 2px 8px; border-radius: 6px; font-size: 12px; font-weight: 700; }
</style>
```

> [!tip] Совет
> Центрирование абсолютного элемента: `inset: 0; margin: auto;` (если задан размер) или `top: 50%; left: 50%; transform: translate(-50%, -50%);`.

## fixed и sticky

```css
.chat-button {
  position: fixed;
  right: 24px;
  bottom: 24px;  /* всегда в правом нижнем углу экрана */
}

.site-header {
  position: sticky;
  top: 0;        /* прилипает к верху при прокрутке */
}
```

`sticky` не работает, если у кого-то из предков `overflow: hidden` или если не задан порог (`top`).

```html preview
<div class="scroll">
  <h4 class="sticky">Я прилипаю (прокрутите блок)</h4>
  <p>Строка 1</p><p>Строка 2</p><p>Строка 3</p><p>Строка 4</p><p>Строка 5</p><p>Строка 6</p><p>Строка 7</p><p>Строка 8</p>
</div>
<style>
  .scroll { height: 160px; overflow: auto; border: 2px solid #222; font-family: sans-serif; }
  .sticky { position: sticky; top: 0; margin: 0; padding: 8px; background: #ffd36b; }
  p { margin: 10px; }
</style>
```

## z-index и контекст наложения

Когда элементы перекрываются, кто сверху — решает `z-index` (работает у позиционированных элементов, а также у flex- и grid-детей). Больше — выше.

```css
.modal-overlay { position: fixed; inset: 0; z-index: 100; }
.dropdown { position: absolute; z-index: 10; }
```

Подвох: `z-index` сравнивается только внутри одного **контекста наложения**. Его создают, например, `position` + `z-index`, `opacity < 1`, `transform`. Ребёнок с `z-index: 9999` не поднимется выше «дяди», если его родитель в контексте ниже. Если `z-index` «не работает» — ищите, кто из предков создал контекст.

> [!tip] Совет
> Заведите шкалу слоёв: `--z-dropdown: 10; --z-header: 50; --z-modal: 100;` — и не пишите случайных `z-index: 99999`.

## transform: сдвиг без влияния на поток

`transform: translate(10px, 20px)` визуально сдвигает элемент, не трогая соседей, и анимируется очень плавно (видеокарта). Ещё есть `scale()`, `rotate()`, `skew()`. Подробнее — на станции «Переходы и анимации».
