Селектор решает, **к чему** применить стили. Чем лучше вы знаете селекторы, тем меньше лишних классов в разметке и тем короче CSS.

## Комбинаторы: отношения между элементами

| Комбинатор | Пример | Выбирает |
|---|---|---|
| пробел (потомок) | `nav a` | все `a` где угодно внутри `nav` |
| `>` (дочерний) | `ul > li` | `li`, которые прямые дети `ul` |
| `+` (соседний) | `h2 + p` | `p`, идущий **сразу** после `h2` |
| `~` (сиблинги) | `h2 ~ p` | все `p` после `h2` на том же уровне |

```html preview
<article>
  <h2>Заголовок</h2>
  <p>Первый абзац сразу после h2 — он крупнее.</p>
  <p>Второй абзац.</p>
  <div><p>Вложенный абзац в div.</p></div>
</article>
<style>
  article p { color: #555; }
  article > p { border-left: 3px solid #2167c9; padding-left: 8px; }
  h2 + p { font-size: 20px; }
</style>
```

## Селекторы атрибутов

```css
a[target="_blank"] { }      /* точное значение */
a[href^="https"] { }        /* начинается с */
a[href$=".pdf"] { }         /* заканчивается на */
img[alt] { }                /* атрибут просто есть */
input[type="email"] { }
```

Например, можно автоматически добавить значок к ссылкам на PDF без единого класса.

## Псевдоклассы: состояния

Псевдокласс начинается с двоеточия и выбирает элемент в определённом **состоянии** или **положении**.

Состояния взаимодействия:

```css
a:hover { }          /* курсор над элементом */
button:active { }    /* в момент нажатия */
input:focus { }      /* в фокусе */
button:focus-visible { } /* фокус с клавиатуры — для обводки */
input:checked { }    /* отмеченный чекбокс */
input:disabled { }
input:invalid { }    /* не прошло встроенную валидацию */
```

Структурные:

```css
li:first-child { }
li:last-child { }
li:nth-child(2) { }       /* второй */
li:nth-child(odd) { }     /* нечётные: 1, 3, 5… */
tr:nth-child(2n) { }      /* чётные */
li:nth-child(3n + 1) { }  /* 1, 4, 7… */
p:not(.lead) { }          /* все, кроме */
```

```html preview
<ul class="list">
  <li>Первый</li><li>Второй</li><li>Третий</li><li>Четвёртый</li><li>Пятый</li>
</ul>
<button>Наведи и нажми</button>
<style>
  .list li:nth-child(odd) { background: #eef3fb; }
  .list li:first-child { font-weight: bold; }
  .list li:last-child { color: tomato; }
  button { padding: 8px 14px; border: 2px solid #222; background: white; }
  button:hover { background: #ffd36b; }
  button:active { transform: translateY(2px); }
  button:focus-visible { outline: 3px solid #2167c9; }
</style>
```

## Современные псевдоклассы: :is, :where, :has

`:is()` сокращает повторения:

```css
/* было */
header a:hover, footer a:hover, nav a:hover { }
/* стало */
:is(header, footer, nav) a:hover { }
```

`:where()` — то же, но с **нулевой специфичностью** (см. следующую станцию) — удобно для базовых стилей, которые легко переопределить.

`:has()` — «родительский селектор», долгожданная возможность CSS: выбрать элемент, **если внутри него** есть что-то.

```css
.card:has(img) { padding: 0; }            /* карточка, в которой есть картинка */
label:has(input:checked) { color: green; } /* подпись отмеченного чекбокса */
form:has(:invalid) button { opacity: .5; } /* кнопка, пока в форме есть ошибки */
```

## Псевдоэлементы

Псевдоэлемент (два двоеточия) — «виртуальная» часть элемента:

```css
.price::before { content: "от "; }   /* вставить контент перед */
.required::after { content: " *"; color: red; }
p::first-line { font-weight: bold; }
p::first-letter { font-size: 2em; }
::selection { background: yellow; }  /* выделенный текст */
input::placeholder { color: #999; }
```

У `::before` и `::after` обязательно свойство `content` (хотя бы пустое `""`), иначе они не появятся. Их часто используют для декоративных элементов: иконок, подчёркиваний, оверлеев.
