Конечная первой линии! Время собрать всё вместе: скелет документа, текст, ссылки, картинки, списки, таблицы, семантику и форму. Проект — **страница-резюме** на чистом HTML. На следующей линии мы её оформим.

## Что должно получиться

Структура страницы:

```text
header
 ├─ h1 — ваше имя
 └─ nav — ссылки-якоря на разделы
main
 ├─ section#about — фото и пара абзацев о себе
 ├─ section#skills — список навыков
 ├─ section#experience — таблица опыта / учёбы
 └─ section#contact — форма обратной связи
footer — контакты и год
```

## Чек-лист перед сдачей

- [x] Есть `<!DOCTYPE html>`, `lang="ru"`, `charset`, `viewport`, `title`.
- [x] Один `h1`, у каждого раздела свой `h2`, уровни не прыгают.
- [x] Навигация — список ссылок-якорей в `<nav>`.
- [x] У фото есть осмысленный `alt` и размеры.
- [x] Таблица с `caption`, `thead`, `th scope`.
- [x] У каждого поля формы — `label`, у обязательных — `required`, у email — правильный `type`.
- [x] Ни одного `div`, где подходит смысловой тег.

> [!tip] Совет
> Откройте результат и пройдитесь по нему только клавишей <kbd>Tab</kbd>. Удаётся ли дойти до всех ссылок и полей? Понятно ли, где вы находитесь? Это быстрый тест доступности.

## Как работать над проектом

1. Сначала набросайте **только структуру** — теги без текста.
2. Затем наполните контентом.
3. Проверьте разметку [валидатором](https://validator.w3.org/nu/) (в реальном проекте).
4. Нажмите «Проверить» — автопроверка пройдётся по чек-листу.

Работа большая — код сохраняется автоматически, можно возвращаться.
