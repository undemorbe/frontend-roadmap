Массив — упорядоченный список значений. Список задач, товары в корзине, сообщения в чате — это массивы. А методы массивов `map`, `filter`, `reduce` — то, чем вы будете пользоваться каждый день, особенно во Vue.

## Основы

```js
const lines = ['HTML', 'CSS', 'JS']

lines[0]          // 'HTML' — индексы с нуля
lines.at(-1)      // 'JS' — с конца
lines.length      // 3
lines[1] = 'Sass' // заменить элемент

Array.isArray(lines) // true
```

## Добавление и удаление (изменяют массив)

```js
const arr = [1, 2, 3]
arr.push(4)         // в конец → [1, 2, 3, 4]
arr.pop()           // убрать с конца → [1, 2, 3]
arr.unshift(0)      // в начало → [0, 1, 2, 3]
arr.shift()         // убрать из начала → [1, 2, 3]
arr.splice(1, 1)    // с индекса 1 удалить 1 элемент → [1, 3]
arr.splice(1, 0, 2) // вставить 2 на индекс 1 → [1, 2, 3]
```

Эти методы **мутируют** (изменяют) исходный массив. Методы ниже возвращают **новый** массив, не трогая исходный — это безопаснее.

```js
const copy = [...arr]                 // копия
const joined = [...arr, ...other]     // склейка
const part = arr.slice(1, 3)          // кусок с 1 по 3 (не включая)
const sorted = arr.toSorted()         // отсортированная копия (ES2023)
```

## Поиск

```js
const users = [
  { id: 1, name: 'Аня', age: 25 },
  { id: 2, name: 'Олег', age: 17 },
  { id: 3, name: 'Ира', age: 31 },
]

users.find((u) => u.id === 2)        // { id: 2, ... } — первый подходящий элемент
users.findIndex((u) => u.id === 2)   // 1
users.some((u) => u.age < 18)        // true — есть хотя бы один
users.every((u) => u.age > 10)       // true — все
['a', 'b'].includes('b')             // true
```

## Тройка главных методов

**`map`** — преобразовать каждый элемент, получить новый массив той же длины:

```js
const names = users.map((u) => u.name)          // ['Аня', 'Олег', 'Ира']
const doubled = [1, 2, 3].map((n) => n * 2)     // [2, 4, 6]
```

**`filter`** — оставить элементы, для которых колбэк вернул `true`:

```js
const adults = users.filter((u) => u.age >= 18)
```

**`reduce`** — свернуть массив в одно значение:

```js
const totalAge = users.reduce((sum, u) => sum + u.age, 0)  // 73
//                            ^ накопитель   ^ начальное значение
```

Их удобно соединять в цепочку:

```js preview
const products = [
  { title: 'Чай', price: 120, inStock: true },
  { title: 'Кофе', price: 180, inStock: false },
  { title: 'Торт', price: 250, inStock: true },
]

const total = products
  .filter((p) => p.inStock)
  .map((p) => p.price)
  .reduce((sum, price) => sum + price, 0)

console.log('В наличии на сумму:', total)
console.log(products.map((p) => p.title).join(', '))
```

`forEach` просто перебирает элементы (ничего не возвращает) — для побочных действий вроде вывода.

> [!info] Как это связано
> Во Vue `v-for` выводит массив, а `computed`-свойства почти всегда — это `filter`/`map`/`reduce` над массивом из состояния. Отфильтрованный список задач, сумма корзины, поиск — всё здесь.

## Сортировка

```js
const nums = [10, 1, 5]
nums.sort()                       // [1, 10, 5] — сравнивает как строки!
nums.sort((a, b) => a - b)        // [1, 5, 10] — по возрастанию
users.sort((a, b) => a.name.localeCompare(b.name)) // по алфавиту
```

`sort` мутирует массив. Если исходный нужно сохранить — `toSorted` или `[...arr].sort()`.

## Деструктуризация массивов

```js
const [first, second, ...others] = ['a', 'b', 'c', 'd']
let x = 1, y = 2;
[x, y] = [y, x]   // обмен значениями
```

## Set и Map

- `Set` — коллекция **уникальных** значений: `[...new Set([1, 1, 2])]` → `[1, 2]`.
- `Map` — как объект, но ключом может быть что угодно и порядок гарантирован: `map.set(key, value)`, `map.get(key)`.
