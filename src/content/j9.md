Событие — сигнал, что что-то произошло: клик, ввод текста, отправка формы, прокрутка, загрузка страницы. Интерактивность в вебе — это **реакция на события**. Пересадки: станция «Формы» (HTML) и «Переходы и анимации» (CSS).

## addEventListener

```js
const button = document.querySelector('button')

button.addEventListener('click', () => {
  console.log('Клик!')
})
```

Первый аргумент — тип события, второй — **обработчик** (колбэк), который вызовется при каждом событии.

Частые события:

| Событие | Когда |
|---|---|
| `click` | Клик (и нажатие Enter/Space на кнопке) |
| `input` | Каждое изменение значения поля |
| `change` | Значение изменено и подтверждено (потеря фокуса, выбор в select) |
| `submit` | Отправка формы |
| `keydown` / `keyup` | Нажатие / отпускание клавиши |
| `focus` / `blur` | Получение / потеря фокуса |
| `mouseenter` / `mouseleave` | Наведение курсора |
| `scroll`, `resize` | Прокрутка, изменение размера окна |
| `DOMContentLoaded` | HTML разобран, DOM готов |

Снять обработчик: `button.removeEventListener('click', handler)` — нужна ссылка на ту же функцию. Однократный: `addEventListener('click', fn, { once: true })`.

## Объект события

Обработчик получает объект события с подробностями:

```js
input.addEventListener('input', (event) => {
  console.log(event.target.value)   // элемент, на котором произошло событие
})

document.addEventListener('keydown', (e) => {
  if (e.key === 'Escape') closeModal()
  if (e.key === 'k' && (e.ctrlKey || e.metaKey)) openSearch()
})
```

`event.target` — где произошло событие, `event.currentTarget` — на чьём обработчике мы сейчас. Для мыши есть `clientX/clientY`, для клавиатуры — `key`.

```html preview
<button class="btn">Нажато: 0</button>
<input class="field" placeholder="Печатайте…">
<p class="out"></p>
<script>
  let count = 0
  const btn = document.querySelector('.btn')
  btn.addEventListener('click', () => {
    count++
    btn.textContent = `Нажато: ${count}`
  })
  const out = document.querySelector('.out')
  document.querySelector('.field').addEventListener('input', (e) => {
    out.textContent = `Длина: ${e.target.value.length}`
  })
</script>
```

## Действия по умолчанию

У многих событий есть встроенное поведение: ссылка переходит, форма отправляется и перезагружает страницу. `event.preventDefault()` его отменяет:

```js
form.addEventListener('submit', (e) => {
  e.preventDefault()                 // не перезагружать страницу
  const data = new FormData(form)    // собрать поля по name
  console.log(data.get('email'))
})
```

> [!tip] Совет
> Слушайте `submit` на **форме**, а не `click` на кнопке: так сработает и отправка по Enter, а встроенная валидация (`required`, `type="email"`) отработает до вашего кода.

## Всплытие и делегирование

Событие сначала происходит на элементе, а потом **всплывает** вверх по дереву: на родителе, его родителе — до `document`. Поэтому один обработчик на контейнере может обслуживать всех детей — это **делегирование**:

```js
// вместо обработчика на каждой кнопке «удалить»:
list.addEventListener('click', (e) => {
  const btn = e.target.closest('.delete')
  if (!btn) return                    // кликнули не по кнопке
  btn.closest('li').remove()
})
```

Плюсы: один обработчик вместо сотни и работает для элементов, добавленных позже. `e.stopPropagation()` останавливает всплытие (нужно редко).

## Состояние и интерфейс

Хорошая практика — хранить **состояние** в переменных и перерисовывать интерфейс из него:

```js
const state = { open: false }

toggle.addEventListener('click', () => {
  state.open = !state.open
  menu.classList.toggle('open', state.open)   // второй аргумент — принудительно
  toggle.setAttribute('aria-expanded', state.open)
})
```

Анимацию открытия сделает CSS-`transition` на классе `.open`.
