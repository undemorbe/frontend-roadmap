Пересадка с линии HTML выполнена. CSS (Cascading Style Sheets, «каскадные таблицы стилей») отвечает за то, как выглядит разметка: цвета, шрифты, отступы, расположение блоков, анимации.

## Анатомия CSS-правила

```css
h1 {
  color: tomato;
  font-size: 32px;
}
```

- `h1` — **селектор**: к каким элементам применить стили;
- `{ … }` — **блок объявлений**;
- `color: tomato;` — **объявление**: *свойство* `color` и *значение* `tomato`, в конце точка с запятой.

Правил в файле может быть сколько угодно. Свойств — около 500, но в повседневной работе хватает сотни.

```html preview
<h1>Заголовок</h1>
<p class="lead">Абзац с классом lead.</p>
<p>Обычный абзац.</p>
<style>
  h1 { color: tomato; font-family: Georgia, serif; }
  .lead { font-size: 20px; color: #2167c9; }
  p { margin: 4px 0; }
</style>
```

## Три способа подключить CSS

**1. Внешний файл** — основной способ. Стили в отдельном `.css`, подключаются в `<head>`:

```html
<link rel="stylesheet" href="style.css">
```

Один файл стилей используется на всех страницах сайта, а браузер кэширует его.

**2. Тег `<style>`** внутри HTML — для небольших демо или критичных стилей:

```html
<style>
  body { background: #f4f1e9; }
</style>
```

**3. Атрибут `style`** у элемента — инлайновые стили. Использовать редко: их сложно переопределять и поддерживать.

```html
<p style="color: red">Срочно!</p>
```

> [!note] Заметка
> В редакторе практики файлы `index.html` и `style.css` уже связаны — стили подключаются автоматически, как будто в `<head>` стоит `<link>`.

## Синтаксис: мелочи, которые важны

```css
/* Комментарий в CSS — только такой, многострочный */

.card,
.banner {              /* несколько селекторов через запятую */
  margin: 0 auto;      /* значение из нескольких частей */
  font-family: "Open Sans", Arial, sans-serif; /* список: если нет первого — берётся следующий */
  width: calc(100% - 40px); /* функции */
}
```

- Ошибка в одном объявлении (опечатка в свойстве или значении) не ломает остальные — браузер просто **проигнорирует** неизвестное объявление.
- Регистр свойств не важен, но принято писать строчными буквами.
- Последняя точка с запятой в блоке необязательна, но ставьте её — меньше ошибок при добавлении строк.

## Простейшие селекторы

| Селектор | Пример | Выбирает |
|---|---|---|
| По тегу | `p` | все абзацы |
| По классу | `.button` | все элементы с `class="button"` |
| По id | `#header` | элемент с `id="header"` |
| Универсальный | `*` | все элементы |

На практике стили пишут в основном **через классы**: один элемент может иметь несколько классов, а класс можно повесить на любой тег.

```html
<button class="button button-primary">OK</button>
```

```css
.button { padding: 8px 16px; }
.button-primary { background: #2167c9; color: white; }
```

## DevTools: стили на лету

В DevTools → Elements выберите элемент — справа во вкладке **Styles** видны все правила, которые к нему применились, и зачёркнутые — которые проиграли. Значения можно менять прямо там и сразу видеть результат. Это главный инструмент верстальщика: экспериментируйте в браузере, а удачное переносите в код.
