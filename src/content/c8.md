Если Flexbox — это раскладка в одну линию, то **Grid** — в двух измерениях сразу: строки и столбцы. Сетки галерей, макеты страниц, дашборды, карточки товаров — работа для Grid.

## Включаем сетку

```css
.grid {
  display: grid;
  grid-template-columns: 200px 1fr 1fr; /* три колонки */
  gap: 16px;
}
```

Дети контейнера автоматически раскладываются по ячейкам слева направо, сверху вниз. Новые строки создаются сами по мере надобности.

## Единица fr и repeat()

`fr` (fraction) — доля свободного пространства. `1fr 2fr` — вторая колонка вдвое шире первой.

```css
grid-template-columns: repeat(3, 1fr);       /* три равные колонки */
grid-template-columns: 250px repeat(2, 1fr); /* фикс + две резиновые */
grid-template-rows: auto 1fr auto;           /* шапка, контент, подвал */
```

```html preview
</div>

```

## Адаптивная сетка без медиазапросов

Самый полезный рецепт Grid — одна строка:

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}
```

Что тут происходит: «сделай столько колонок, сколько влезет (`auto-fit`), каждая — минимум 220px, максимум 1fr». На широком экране будет 5 колонок, на телефоне — одна.

`minmax(min, max)` — размер трека в диапазоне. `auto-fill` похож на `auto-fit`, но оставляет пустые колонки, если элементов мало.

## Размещение элементов

Элемент может занять несколько ячеек — по номерам **линий** сетки (линии нумеруются с 1, `-1` — последняя):

```css
.featured {
  grid-column: 1 / 3;    /* от 1-й до 3-й линии = 2 колонки */
  grid-row: span 2;      /* растянуться на 2 строки */
}
.full-width {
  grid-column: 1 / -1;   /* на всю ширину */
}
```

```html preview

  <div class="big">big: span 2 × 2</div><div>2</div><div>3</div><div>4</div><div>5</div><div class="wide">wide: 1 / -1</div>
</div>
<style>
  .g { display: grid; grid-template-columns: repeat(4, 1fr); gap: 8px; font: 700 15px sans-serif; }
  .g div { background: #ffe9a8; padding: 16px; border-radius: 8px; }
  .big { grid-column: span 2; grid-row: span 2; background: #ffd36b !important; }
  .wide { grid-column: 1 / -1; background: #c9ddff !important; }
</style>
```

## Именованные области

Самый наглядный способ описать макет страницы — нарисовать его словами:

```css
.page {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  min-height: 100vh;
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }
```

Точка `.` в шаблоне — пустая ячейка. А на телефоне достаточно переписать только `grid-template-areas` в медиазапросе.

## Выравнивание в Grid

- `justify-items` / `align-items` — выравнивание содержимого внутри ячеек (по горизонтали/вертикали);
- `place-items: center` — сокращение для обоих;
- `justify-self` / `align-self` — для одного элемента;
- `justify-content` / `align-content` — выравнивание всей сетки внутри контейнера.

## Grid или Flexbox?

| Задача | Инструмент |
|---|---|
| Элементы в один ряд, размеры от содержимого (меню, кнопки, теги) | Flexbox |
| Строки **и** столбцы, жёсткая структура (галерея, макет) | Grid |
| Центрировать один элемент | Оба: `place-items: center` на Grid короче |

Их отлично комбинируют: макет страницы — на Grid, шапка внутри — на Flexbox.
