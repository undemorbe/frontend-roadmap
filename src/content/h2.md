HTML (HyperText Markup Language) — язык **разметки**. Он не программирует, а *описывает*: «это заголовок», «это абзац», «это ссылка». Браузер читает разметку и строит из неё страницу.

## Теги и элементы

Разметка состоит из **тегов** — слов в угловых скобках. Большинство тегов парные: открывающий и закрывающий (со слешем). Всё вместе — открывающий тег, содержимое и закрывающий — называется **элементом**.

```html
<p>Это абзац текста.</p>
```

Некоторые элементы **пустые (одиночные)**: у них нет содержимого и закрывающего тега.

```html
<br>                         <!-- перенос строки -->
<img src="cat.jpg" alt="Кот">  <!-- картинка -->
<input type="text">          <!-- поле ввода -->
```

> [!note] Заметка
> Можно встретить запись `<br />` со слешем в конце. В HTML5 это допустимо, но не обязательно. Во Vue-шаблонах самозакрывающаяся запись нормальна и для компонентов: `<MyButton />`.

## Вложенность

Элементы можно вкладывать друг в друга. Главное правило: **закрывайте теги в обратном порядке** — как матрёшки.

```html
<!-- Правильно -->
<p>Это <strong>очень</strong> важно</p>

<!-- Неправильно: теги «перехлёстываются» -->
<p>Это <strong>очень</p> важно</strong>
```

Вложенные элементы называют **дочерними**, внешний — **родительским**. Элементы на одном уровне — **соседние (сиблинги)**. Эти слова пригодятся в CSS-селекторах и в JavaScript.

Чтобы видеть вложенность, код пишут с **отступами** — обычно 2 пробела на уровень. Браузеру отступы не важны, людям — очень.

## Атрибуты

Атрибуты дают элементу дополнительную информацию. Пишутся в открывающем теге: `имя="значение"`.

```html
<a href="https://htmlacademy.ru" target="_blank">HTML Academy</a>
<img src="logo.png" alt="Логотип" width="120">
<input type="checkbox" checked>
```

- `href`, `src`, `alt` — специфичные атрибуты конкретных тегов;
- `id` (уникальный идентификатор) и `class` (один или несколько классов через пробел) — **глобальные**, их можно поставить любому элементу. Через них элемент находят CSS и JavaScript;
- `checked`, `disabled`, `required` — **булевы** атрибуты: само наличие означает «да».

## Скелет документа

Каждый HTML-файл начинается с одинакового «скелета». Его стоит выучить наизусть (в VS Code он вставляется, если набрать `!` и нажать <kbd>Tab</kbd>):

```html
<!DOCTYPE html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Моя первая страница</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <h1>Привет!</h1>
    <script src="script.js"></script>
  </body>
</html>
```

| Строка | Что значит |
|---|---|
| `<!DOCTYPE html>` | «Это современный HTML5». Без неё браузер включит режим совместимости со старыми сайтами |
| `<html lang="ru">` | Корень документа. `lang` помогает скринридерам и переводчикам |
| `<head>` | Служебная информация: не показывается на странице |
| `<meta charset="UTF-8">` | Кодировка. Без неё кириллица может превратиться в «кракозябры» |
| `<meta name="viewport">` | Правильный масштаб на телефонах — обязателен для адаптивности |
| `<title>` | Текст во вкладке браузера и в поисковой выдаче |
| `<body>` | Всё видимое содержимое страницы |

## Комментарии

Комментарии видны в коде, но не на странице. Ими объясняют сложные места или временно «выключают» кусок разметки:

```html
<!-- Это комментарий. Браузер его не покажет -->
```

## Как браузер исправляет ошибки

HTML очень «прощающий»: забытые закрывающие теги браузер часто достроит сам. Но полагаться на это нельзя — результат может отличаться от задуманного. Проверить разметку можно [валидатором W3C](https://validator.w3.org/nu/).

```html preview
<h1>Дерево элементов</h1>
<p>Абзац с <strong>жирным</strong> и <em>курсивным</em> текстом.</p>
<p>Ниже ссылка с атрибутами:</p>
<a href="https://developer.mozilla.org/ru/" target="_blank">MDN — справочник</a>
```

> [!info] Как это связано
> Вложенность тегов образует **дерево**. Именно из него браузер строит DOM — с ним вы будете работать на станции «DOM» линии JavaScript. Это пересадка.
