Текст — основа почти любой страницы. На этой станции важно запомнить главную мысль HTML: **тег выбирают по смыслу, а не по внешнему виду**. Вид настраивается в CSS.

## Заголовки h1–h6

Шесть уровней заголовков образуют структуру документа — как оглавление книги:

```html preview
<h1>Рецепт блинов</h1>
<h2>Ингредиенты</h2>
<h3>Для теста</h3>
<h3>Для начинки</h3>
<h2>Приготовление</h2>
```

Правила:

- `h1` — главный заголовок страницы, обычно **один**;
- уровни **не перепрыгивают**: после `h2` идёт `h3`, а не `h5`;
- не выбирайте уровень ради размера шрифта — размер меняется в CSS.

Скринридеры позволяют «прыгать» по заголовкам, а поисковики по ним понимают структуру. Правильные заголовки — бесплатная доступность и SEO.

## Абзацы и переносы

`<p>` — абзац. Браузер схлопывает пробелы и переносы строк в коде в один пробел, поэтому несколько абзацев — это несколько `<p>`, а не «пустые строки».

```html
<p>Первый абзац.</p>
<p>Второй абзац.
   Этот перенос строки браузер проигнорирует.</p>
<p>Принудительный перенос<br>внутри абзаца — через br.</p>
```

`<br>` используют редко: в адресах, стихах. Для отступов между блоками — CSS.

## Выделение по смыслу

| Тег | Смысл | Вид по умолчанию |
|---|---|---|
| `<strong>` | Важность, серьёзность | жирный |
| `<em>` | Логическое ударение | курсив |
| `<mark>` | Подсвеченный фрагмент (например, найденный текст) | жёлтый фон |
| `<small>` | Мелкий шрифт: примечания, юридический текст | меньше |
| `<b>`, `<i>` | Выделение **без** дополнительного смысла (термины, названия) | жирный, курсив |
| `<s>` | Больше не актуально (старая цена) | зачёркнутый |
| `<sup>`, `<sub>` | Верхний и нижний индекс: м², H₂O | выше/ниже строки |

```html preview
<p><strong>Внимание!</strong> Магазин закрыт <em>только</em> сегодня.</p>
<p>Цена: <s>1 990 ₽</s> <mark>1 490 ₽</mark></p>
<p>Площадь 54 м<sup>2</sup>, формула воды H<sub>2</sub>O.</p>
<p><small>Не является публичной офертой.</small></p>
```

## Цитаты, код и прочее

```html
<blockquote cite="https://learn.javascript.ru">
  <p>Программирование — это не только о коде.</p>
</blockquote>
<p>Как говорил классик, <q>краткость — сестра таланта</q>.</p>

<p>Запустите команду <code>npm run dev</code>.</p>
<pre><code>const x = 1
console.log(x)</code></pre>

<p>Нажмите <kbd>Ctrl</kbd> + <kbd>C</kbd>.</p>
<p><abbr title="HyperText Markup Language">HTML</abbr> — язык разметки.</p>
<p>Опубликовано <time datetime="2026-11-09">9 ноября</time>.</p>
```

- `<blockquote>` — блочная цитата, `<q>` — короткая внутри строки (кавычки ставятся сами);
- `<code>` — фрагмент кода, `<pre>` — сохраняет пробелы и переносы (для многострочного кода);
- `<abbr>` — аббревиатура с расшифровкой во всплывающей подсказке;
- `<time datetime="...">` — дата в машиночитаемом формате.

## Спецсимволы (мнемоники)

Некоторые символы в HTML имеют особое значение. Чтобы показать `<` как текст, используют **мнемоники**:

| Пишем | Получаем | Зачем |
|---|---|---|
| `&lt;` `&gt;` | &lt; &gt; | угловые скобки как текст |
| `&amp;` | &amp; | амперсанд |
| `&nbsp;` | неразрывный пробел | «10&nbsp;кг» не разорвётся на две строки |
| `&mdash;` | — | длинное тире |
| `&laquo;` `&raquo;` | « » | кавычки-ёлочки |
| `&copy;` | © | копирайт |

> [!tip] Совет
> Сегодня большинство символов (—, «», ©) можно вставлять прямо в UTF-8-документ. Мнемоники обязательны только для `<`, `>`, `&` и полезны для `&nbsp;`.
