Функция — именованный кусок кода, который можно вызывать много раз. Функции — главный строительный блок программ: обработчики кликов, вычисления, компоненты Vue — всё это функции.

## Объявление и вызов

```js
function greet(name) {          // name — параметр
  return `Привет, ${name}!`     // return возвращает результат
}

const text = greet('Аня')       // 'Аня' — аргумент
console.log(text)               // Привет, Аня!
```

- Параметры — «переменные-входы» функции.
- `return` завершает функцию и возвращает значение. Без `return` функция вернёт `undefined`.
- Хорошая функция делает **одно дело** и называется глаголом: `getTotal`, `formatDate`, `isValidEmail`.

## Параметры по умолчанию и rest

```js
function createUser(name, role = 'student') {  // значение по умолчанию
  return { name, role }
}
createUser('Аня')            // { name: 'Аня', role: 'student' }

function sum(...numbers) {   // rest: все аргументы в массив
  let total = 0
  for (const n of numbers) total += n
  return total
}
sum(1, 2, 3, 4)              // 10
```

## Function Expression и стрелочные функции

Функция в JavaScript — это **значение**. Её можно положить в переменную:

```js
const square = function (x) {
  return x * x
}

// Стрелочная функция — короткая запись
const square2 = (x) => x * x          // если тело — одно выражение, return не нужен
const add = (a, b) => a + b
const log = () => console.log('hi')    // без параметров
const makeUser = (name) => ({ name })  // объект оборачивают в скобки
```

Разница с `function` объявлением: **Function Declaration** доступна во всём коде ещё до строки объявления («всплывает»), а выражения — только после. Ещё у стрелочных функций нет своего `this` (станция «Объекты»).

## Колбэки

Раз функция — значение, её можно передать в другую функцию. Такую функцию называют **колбэком** (callback — «перезвонить»):

```js
function repeat(times, action) {
  for (let i = 0; i < times; i++) action(i)
}

repeat(3, (i) => console.log('Шаг', i))

// Колбэки повсюду:
button.addEventListener('click', () => { /* ... */ })
setTimeout(() => console.log('Прошла секунда'), 1000)
[1, 2, 3].map((n) => n * 2)
```

## Область видимости

Переменная, объявленная через `let`/`const`, видна только **внутри блока** `{ ... }`, где объявлена, и во вложенных блоках.

```js
const global = 'видна везде'

function outer() {
  const local = 'видна только в outer'
  if (true) {
    const block = 'видна только в этом if'
    console.log(global, local, block)  // всё доступно
  }
  // console.log(block) — ReferenceError
}
```

Внутренний код видит внешние переменные, а внешний внутренние — нет.

## Замыкания

Функция **запоминает** переменные из места, где была создана, даже после того, как внешняя функция завершилась. Это называется **замыканием**.

```js preview
function createCounter() {
  let count = 0              // «приватная» переменная
  return function () {
    count++
    return count
  }
}

const counter = createCounter()
console.log(counter()) // 1
console.log(counter()) // 2

const other = createCounter() // у каждого вызова — своя count
console.log(other())   // 1
```

Замыкания позволяют прятать данные и создавать «настроенные» функции. Во Vue на них построены composables (`useCounter()`) — пересадка на станцию «Жизненный цикл и composables».

## Чистые функции

**Чистая функция** — результат зависит только от аргументов, и она ничего не меняет снаружи. Её легко тестировать и переиспользовать:

```js
// чистая
const withVat = (price) => price * 1.2

// нечистая: меняет внешнюю переменную
let total = 0
function addToTotal(x) { total += x }
```

Стремитесь к чистым функциям; «грязные» (работа с DOM, сетью) держите отдельно.
