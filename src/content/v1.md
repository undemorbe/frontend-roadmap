Зелёная линия — **Vue.js**, прогрессивный фреймворк для создания интерфейсов. Сюда удобно пересесть со станции «DOM» линии JS: вы уже знаете, как вручную искать элементы и менять их текст. Vue делает это за вас — вы описываете, **как интерфейс зависит от данных**, а Vue сам обновляет страницу при их изменении.

## Зачем фреймворк

Вспомните счётчик на чистом JS:

```js
let count = 0
const btn = document.querySelector('button')
btn.addEventListener('click', () => {
  count++
  btn.textContent = `Нажато: ${count}` // не забыть обновить DOM!
})
```

Пока данных мало, это терпимо. Но когда одно значение выводится в пяти местах, а интерфейс состоит из сотен элементов, ручная синхронизация данных и DOM превращается в источник ошибок. Это **императивный** подход: вы командуете «найди, поменяй».

Vue предлагает **декларативный** подход: вы пишете шаблон («здесь показывать `count`»), а **реактивность** следит, чтобы страница всегда соответствовала данным.

## Первое приложение

Vue можно подключить даже без сборщика — одним тегом `<script>`. На первых станциях линии так и сделаем (в песочнице Vue уже подключён, он доступен как глобальный объект `Vue`):

```html preview vue
<div id="app">
  <h1>{{ message }}</h1>
  <button @click="count++">Нажато: {{ count }}</button>
</div>

<script>
  const { createApp, ref } = Vue

  createApp({
    setup() {
      const message = ref('Привет, Vue!')
      const count = ref(0)
      return { message, count }
    },
  }).mount('#app')
</script>
```

Разберём по частям:

- `createApp({...})` создаёт приложение из **корневого компонента** — объекта с настройками.
- `setup()` — функция, где объявляется состояние. Всё, что она **возвращает**, доступно в шаблоне.
- `ref(0)` создаёт **реактивное значение**. Когда оно меняется, Vue перерисовывает зависимые части.
- `.mount('#app')` — «монтирует» приложение в элемент. Содержимое `#app` становится **шаблоном**.
- `{{ count }}` — **интерполяция**: вывод значения в текст.
- `@click="count++"` — обработчик события (подробнее — на следующей станции).

## Интерполяция

Внутри `{{ }}` можно писать любое **JavaScript-выражение** (не инструкцию):

```html
{{ count + 1 }}
{{ ok ? 'Да' : 'Нет' }}
{{ message.toUpperCase() }}
{{ items.length }} шт.
```

А вот `{{ if (ok) {...} }}` или `{{ let x = 1 }}` не сработает — это инструкции, а не выражения. Сложную логику выносят в `setup()`.

> [!info] Безопасность
> Интерполяция выводит **текст**, а не HTML: если в строке будет `<b>`, пользователь увидит символы тега. Это защищает от XSS-атак, как `textContent` в DOM.

## ref и .value

В `setup()` значение `ref` читается и меняется через `.value`, а в шаблоне `.value` писать не нужно — Vue «разворачивает» ref автоматически:

```js
const count = ref(0)
console.log(count.value) // 0
count.value++            // в JS — через .value

// в шаблоне просто: {{ count }}
```

```html preview vue
<div id="app">
  <p>Станций пройдено: {{ passed }} из {{ total }}</p>
  <p>Прогресс: {{ Math.round(passed / total * 100) }}%</p>
  <button @click="next">Следующая станция</button>
</div>

<script>
  const { createApp, ref } = Vue

  createApp({
    setup() {
      const passed = ref(3)
      const total = ref(12)
      function next() {
        if (passed.value < total.value) passed.value++
      }
      return { passed, total, next }
    },
  }).mount('#app')
</script>
```

## Composition API и Options API

У Vue два стиля описания компонентов. В учебнике используется современный **Composition API** (`setup`, `ref`). В старом коде и некоторых туториалах вы встретите **Options API**:

```js
createApp({
  data() {
    return { count: 0 }
  },
  methods: {
    increment() { this.count++ },
  },
}).mount('#app')
```

Оба стиля работают, Composition API лучше масштабируется и удобнее для переиспользования логики. Позже, на станции SFC, вы увидите ещё более короткую форму — `<script setup>`.

## Как Vue устроен в реальном проекте

Подключение через `<script>` хорошо для знакомства. В реальных проектах Vue ставят через npm и Vite (`npm create vue@latest`), а компоненты пишут в файлах `.vue` — это станция «SFC», куда есть пересадка со станции «Старт на Vite».
