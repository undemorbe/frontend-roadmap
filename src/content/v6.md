До сих пор всё приложение было одним большим шаблоном. В реальных интерфейсах его разбивают на **компоненты** — независимые переиспользуемые блоки со своим шаблоном, логикой и стилями: кнопка, карточка, шапка, список. Компонент — как функция: принимает входные данные (**props**) и возвращает кусок интерфейса.

## Дерево компонентов

```text
App
├── AppHeader
│   └── SearchBox
├── StationList
│   ├── StationCard
│   ├── StationCard
│   └── StationCard
└── AppFooter
```

Каждый компонент отвечает за свою часть. `StationCard` написан один раз, а используется сколько угодно.

## Объявление компонента

Компонент — это объект с теми же опциями, что и корневой: `setup`, шаблон и т. д. Пока мы без сборщика, шаблон пишем строкой в опции `template`, а компонент регистрируем в `components`:

```html preview vue
<div id="app">
  <greeting-card name="Анна"></greeting-card>
  <greeting-card name="Борис"></greeting-card>
</div>

<script>
  const { createApp } = Vue

  const GreetingCard = {
    props: ['name'],
    template: `<p class="card">👋 Привет, {{ name }}!</p>`,
  }

  createApp({
    components: { GreetingCard },
  }).mount('#app')
</script>
```

> [!note] Важно про шаблоны в HTML
> Когда шаблон пишется прямо в HTML-странице (как здесь), браузер приводит теги к нижнему регистру. Поэтому компоненты в нём называют через дефис — `<greeting-card>` — и всегда закрывают: `<greeting-card></greeting-card>`. В `.vue`-файлах (станция SFC) можно писать `<GreetingCard />`.

## Props: входные данные

Props лучше объявлять объектом — с типами, значениями по умолчанию и обязательностью. Vue предупредит в консоли, если передано что-то не то:

```js
const StationCard = {
  props: {
    name: { type: String, required: true },
    line: { type: String, default: 'html' },
    minutes: { type: Number, default: 0 },
    tags: { type: Array, default: () => [] },   // объекты и массивы — через функцию
  },
  setup(props) {
    // props реактивны: props.name, props.minutes
  },
  template: `...`,
}
```

Передача пропсов:

```html
<!-- строка — без двоеточия -->
<station-card name="Теги"></station-card>

<!-- число, булево, переменная, выражение — через : (v-bind) -->
<station-card :name="s.name" :minutes="15" :closed="false"></station-card>

<!-- в цикле -->
<station-card v-for="s in stations" :key="s.id" :name="s.name" :line="s.line"></station-card>
```

> [!warn] Частая ошибка
> `minutes="15"` передаст **строку** `"15"`, а не число. Для чисел, `true/false`, массивов и объектов нужен `:`.

## Однонаправленный поток данных

Props текут **сверху вниз**: родитель передаёт данные потомку. Потомок **не должен** менять props — они принадлежат родителю. Если попытаться, Vue выдаст предупреждение, а изменение не дойдёт до родителя.

Если потомку нужно своё изменяемое значение на основе пропса — создайте локальный ref или computed:

```js
setup(props) {
  const count = ref(props.initial)                        // локальная копия
  const label = computed(() => props.name.toUpperCase())  // вычисление из пропса
  return { count, label }
}
```

А чтобы попросить родителя изменить данные, потомок отправляет **событие** — это следующая станция.

## Демо: список карточек

```html preview vue
<div id="app">
  <station-card v-for="s in stations" :key="s.id" :name="s.name" :line="s.line" :minutes="s.minutes"></station-card>
</div>

<script>
  const { createApp, computed } = Vue
  const colors = { html: '#E4402F', css: '#2167C9', js: '#F2B300', vue: '#2E9E6A' }

  const StationCard = {
    props: {
      name: { type: String, required: true },
      line: { type: String, default: 'html' },
      minutes: { type: Number, default: 0 },
    },
    setup(props) {
      const color = computed(() => colors[props.line])
      return { color }
    },
    template: `
      <article :style="{ borderLeft: '6px solid ' + color, padding: '6px 12px', margin: '6px 0' }">
        <b>{{ name }}</b> · {{ minutes }} мин
      </article>`,
  }

  createApp({
    components: { StationCard },
    setup() {
      return {
        stations: [
          { id: 1, name: 'Теги', line: 'html', minutes: 20 },
          { id: 2, name: 'Flexbox', line: 'css', minutes: 35 },
          { id: 3, name: 'Реактивность', line: 'vue', minutes: 30 },
        ],
      }
    },
  }).mount('#app')
</script>
```

## Глобальная и локальная регистрация

```js
const app = createApp(App)
app.component('BaseButton', BaseButton)  // глобально: доступен во всех шаблонах
app.mount('#app')
```

Локальная регистрация (`components: { ... }`) предпочтительнее: видно, откуда компонент, а сборщик может выкинуть неиспользуемые.
