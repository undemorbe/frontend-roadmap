Гипертекст — это текст со ссылками. Именно ссылки превратили набор документов во «всемирную паутину». А изображения делают страницы живыми.

## Ссылки: тег a

```html
<a href="https://vuejs.org">Документация Vue</a>
```

Атрибут `href` (hypertext reference) — адрес, куда ведёт ссылка. Что может быть в `href`:

| Значение | Куда ведёт |
|---|---|
| `https://site.ru/page` | Абсолютный адрес — другой сайт или страница |
| `about.html` | Относительный адрес — файл рядом с текущим |
| `/contacts` | От корня текущего сайта |
| `#prices` | Якорь — элемент с `id="prices"` на этой же странице |
| `mailto:hi@site.ru` | Открыть почтовую программу |
| `tel:+79990000000` | Позвонить (на телефоне) |

Полезные атрибуты:

- `target="_blank"` — открыть в новой вкладке. Используйте для внешних сайтов, а не для каждой ссылки;
- `rel="noopener"` — безопасность при `_blank` (современные браузеры ставят его сами, но писать не вредно);
- `download` — скачать файл вместо перехода.

> [!warn] Осторожно
> Текст ссылки должен объяснять, куда она ведёт. «Нажмите **здесь**» — плохо: скринридеры зачитывают список ссылок без контекста, и пользователь услышит пять одинаковых «здесь». Лучше: «Скачать **прайс-лист в PDF**».

## Пути к файлам

Представим структуру проекта:

```text
site/
├── index.html
├── about.html
├── blog/
│   └── post.html
└── img/
    └── logo.png
```

- Из `index.html` на логотип: `img/logo.png`
- Из `blog/post.html` на логотип: `../img/logo.png` (`..` — подняться на папку выше)
- От корня сайта (откуда угодно): `/img/logo.png`

## Изображения: тег img

```html
<img src="img/cat.jpg" alt="Рыжий кот спит на подоконнике" width="600" height="400">
```

- `src` — путь к картинке;
- `alt` — **текстовая альтернатива**. Её прочитает скринридер, её покажет браузер, если картинка не загрузилась. Описывайте смысл картинки. Если картинка чисто декоративная — оставьте `alt=""` (пустым, но не удаляйте атрибут);
- `width` и `height` — исходные пропорции. Браузер заранее резервирует место, и страница не «прыгает» при загрузке.

Форматы: **JPEG** — фото; **PNG** — графика с прозрачностью; **SVG** — векторные иконки и логотипы; **WebP/AVIF** — современные, легче JPEG/PNG при том же качестве.

```html preview
<img src="https://picsum.photos/id/237/300/180" alt="Чёрный щенок смотрит в камеру" width="300" height="180">
<p><img src="nope.jpg" alt="Эта картинка не загрузилась — виден alt"></p>
```

## Подписи: figure и figcaption

Когда у изображения (схемы, графика, фото) есть подпись, их объединяют:

```html
<figure>
  <img src="chart.png" alt="Рост продаж с января по июнь">
  <figcaption>Рис. 1. Продажи за полгода выросли вдвое</figcaption>
</figure>
```

## Адаптивные изображения

Телефону не нужно скачивать картинку шириной 3000px. Атрибут `srcset` позволяет дать браузеру выбор:

```html
<img
  src="photo-800.jpg"
  srcset="photo-400.jpg 400w, photo-800.jpg 800w, photo-1600.jpg 1600w"
  sizes="(max-width: 600px) 100vw, 50vw"
  alt="Горы на закате">
```

А `<picture>` — выбрать формат или вовсе другую картинку:

```html
<picture>
  <source srcset="photo.avif" type="image/avif">
  <source srcset="photo.webp" type="image/webp">
  <img src="photo.jpg" alt="Горы на закате">
</picture>
```

Ленивая загрузка: `loading="lazy"` откладывает загрузку картинок ниже первого экрана.

## Ссылка-картинка

В ссылку можно обернуть что угодно, в том числе картинку. Тогда `alt` картинки становится текстом ссылки:

```html
<a href="/"><img src="logo.svg" alt="На главную"></a>
```
