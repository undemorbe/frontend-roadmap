У компонента есть жизнь: он создаётся, появляется на странице, обновляется и исчезает. На некоторые моменты нужно реагировать — поставить фокус в поле, запустить таймер, подписаться на событие окна, а потом всё убрать. Для этого есть **хуки жизненного цикла**. А повторяющуюся логику с состоянием выносят в **composables** — функции-помощники.

## Хуки жизненного цикла

```text
setup ─► onBeforeMount ─► onMounted ─► (onBeforeUpdate ─► onUpdated)* ─► onBeforeUnmount ─► onUnmounted
          (DOM ещё нет)    (DOM есть)     при каждом обновлении            перед удалением     удалён
```

Самые используемые:

| Хук | Когда | Для чего |
|---|---|---|
| `onMounted` | Компонент вставлен в DOM | Фокус, измерения, сторонние библиотеки, подписки |
| `onUnmounted` | Компонент удалён | Отписки, `clearInterval`, `removeEventListener` |
| `onUpdated` | После перерисовки | Редко; обычно хватает `watch` |

```vue
<script setup>
import { ref, onMounted, onUnmounted } from 'vue'

const width = ref(window.innerWidth)
const onResize = () => (width.value = window.innerWidth)

onMounted(() => window.addEventListener('resize', onResize))
onUnmounted(() => window.removeEventListener('resize', onResize))
</script>
```

> [!warn] Утечки
> Всё, что компонент «включил» снаружи себя (таймеры, обработчики на `window`/`document`, WebSocket), он обязан выключить в `onUnmounted`. Иначе после ухода со страницы таймеры продолжат работать, а обработчики — ссылаться на удалённый компонент.

Загрузку данных можно начинать прямо в `setup` — `onMounted` для этого не обязателен, если не нужен DOM.

## Ссылки на элементы (template refs)

Иногда нужен сам DOM-элемент: поставить фокус, прокрутить, измерить. Атрибут `ref` в шаблоне связывает элемент с переменной:

```vue
<script setup>
import { ref, onMounted } from 'vue'

const input = ref(null)          // имя совпадает со значением атрибута ref

onMounted(() => {
  input.value.focus()            // до монтирования здесь null
})
</script>

<template>
  <input ref="input" placeholder="Курсор уже здесь">
</template>
```

В Vue 3.5+ есть и явный способ: `const input = useTemplateRef('my-input')` с атрибутом `ref="my-input"`.

## Composables: переиспользуемая логика

Composable — обычная функция, которая использует Composition API (`ref`, `computed`, `watch`, хуки) и возвращает реактивное состояние. По соглашению имя начинается с `use`.

```js
// useMouse.js
import { ref, onMounted, onUnmounted } from 'vue'

export function useMouse() {
  const x = ref(0)
  const y = ref(0)
  const update = (e) => { x.value = e.pageX; y.value = e.pageY }

  onMounted(() => window.addEventListener('mousemove', update))
  onUnmounted(() => window.removeEventListener('mousemove', update))

  return { x, y }
}
```

```vue
<script setup>
import { useMouse } from './useMouse.js'
const { x, y } = useMouse()
</script>

<template>Курсор: {{ x }}, {{ y }}</template>
```

Каждый вызов `useMouse()` создаёт **своё** состояние. Хуки внутри composable привязываются к компоненту, который его вызвал, — поэтому отписка произойдёт сама.

Популярные composables не нужно писать самим — есть библиотека **VueUse** (`useLocalStorage`, `useFetch`, `useDark`, `useIntersectionObserver` и ещё 200+).

Пример composable для загрузки данных:

```js
export function useFetch(url) {
  const data = ref(null)
  const error = ref(null)
  const loading = ref(true)

  fetch(url)
    .then((r) => r.json())
    .then((json) => (data.value = json))
    .catch((e) => (error.value = e))
    .finally(() => (loading.value = false))

  return { data, error, loading }
}
```
