Движение помогает пользователю понять, что произошло: кнопка нажалась, меню открылось, элемент добавился. В CSS есть два инструмента: **переходы** (из состояния А в состояние Б) и **анимации по ключевым кадрам** (сложные сценарии).

## transition: плавная смена состояния

Без перехода изменения происходят мгновенно. `transition` говорит браузеру: «когда это свойство изменится — проиграй изменение за N секунд».

```css
.button {
  background: #2167c9;
  transition: background-color 0.2s ease, transform 0.2s ease;
}
.button:hover {
  background: #174a91;
  transform: translateY(-2px);
}
```

Формат: `transition: свойство длительность функция-времени задержка`.

- **свойство** — что анимировать (`all` — всё, но лучше перечислять явно);
- **длительность** — `0.2s` или `200ms`. Для интерфейса обычно 150–300 мс;
- **функция времени (easing)** — характер движения:
  - `ease` (по умолчанию), `ease-in-out` — мягкий старт и финиш;
  - `ease-out` — быстрый старт, плавное торможение. Лучше всего для появления элементов;
  - `linear` — равномерно (крутилки-спиннеры);
  - `cubic-bezier(.2, .8, .2, 1)` — своя кривая.

```html preview
<button class="b">Наведи на меня</button>
<div class="box"></div>
<style>
  .b { padding: 12px 20px; border: 0; border-radius: 10px; background: #2167c9; color: white; font: 600 16px sans-serif; cursor: pointer;
       transition: background-color .2s ease, transform .2s ease, box-shadow .2s ease; }
  .b:hover { background: #e4402f; transform: translateY(-3px); box-shadow: 0 6px 0 #222; }
  .box { width: 60px; height: 60px; margin-top: 16px; background: #ffd36b; border-radius: 8px; transition: transform .6s cubic-bezier(.2,.8,.2,1); }
  .b:hover + .box { transform: translateX(200px) rotate(180deg); }
</style>
```

## transform

Трансформации меняют элемент визуально, не трогая раскладку соседей:

```css
transform: translate(20px, 10px);   /* сдвиг; также translateX / translateY */
transform: scale(1.1);              /* масштаб */
transform: rotate(45deg);           /* поворот */
transform: skew(10deg);             /* наклон */
transform: translateY(-4px) scale(1.02); /* несколько сразу — порядок важен */
transform-origin: top left;         /* точка, относительно которой трансформируем */
```

> [!tip] Совет
> Анимируйте **`transform` и `opacity`** — их браузер обрабатывает на видеокарте, без перерасчёта раскладки. Анимация `width`, `height`, `top`, `margin` заставляет пересчитывать страницу на каждом кадре и может «подтормаживать».

## @keyframes: анимации

Когда нужно больше двух состояний или анимация должна запускаться сама — используют ключевые кадры:

```css
@keyframes pulse {
  0%   { transform: scale(1); opacity: 1; }
  50%  { transform: scale(1.15); opacity: .7; }
  100% { transform: scale(1); opacity: 1; }
}

.dot {
  animation: pulse 1.5s ease-in-out infinite;
}
```

Свойства `animation`:

| Свойство | Значения |
|---|---|
| `animation-name` | имя `@keyframes` |
| `animation-duration` | `1s` |
| `animation-timing-function` | `ease`, `linear`, `steps(4)`… |
| `animation-delay` | задержка перед стартом |
| `animation-iteration-count` | число повторов или `infinite` |
| `animation-direction` | `normal`, `reverse`, `alternate` (туда-обратно) |
| `animation-fill-mode` | `forwards` — остаться в конечном кадре |
| `animation-play-state` | `paused` / `running` |

```html preview
<div class="loader"><i></i><i></i><i></i></div>
<p class="appear">Я появляюсь снизу</p>
<style>
  .loader { display: flex; gap: 8px; }
  .loader i { width: 16px; height: 16px; border-radius: 50%; background: #2e9e6a; animation: bounce .9s ease-in-out infinite; }
  .loader i:nth-child(2) { animation-delay: .15s; }
  .loader i:nth-child(3) { animation-delay: .3s; }
  @keyframes bounce { 0%, 100% { transform: translateY(0); } 50% { transform: translateY(-14px); } }
  .appear { font: 600 18px sans-serif; animation: up .8s ease-out both; animation-delay: .3s; }
  @keyframes up { from { opacity: 0; transform: translateY(20px); } to { opacity: 1; transform: none; } }
</style>
```

Приём «каскадного» появления — разные `animation-delay` у соседних элементов.

## Уважайте настройки пользователя

Некоторых людей движение на экране укачивает, у других вызывает проблемы с концентрацией. В ОС есть настройка «уменьшить движение», и CSS её видит:

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

## Принципы хорошей анимации

- **Цель, а не украшение.** Анимация должна объяснять: откуда появилось, куда исчезло, что изменилось.
- **Быстро.** Интерфейсные переходы — 150–300 мс. Дольше — раздражает.
- **Появление — `ease-out`, исчезновение — `ease-in`** и чуть быстрее.
- Без анимации на каждом элементе — внимание рассеивается.

> [!info] Как это связано
> Анимации часто запускаются из JavaScript: добавили класс по клику — сработал `transition`. Это пересадка на станцию «События». А во Vue для появления/исчезновения есть компонент `<Transition>`.
