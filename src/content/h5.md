Списки и таблицы — способы упорядочить информацию. Меню сайта, шаги инструкции, характеристики товара, расписание — всё это списки и таблицы.

## Маркированный список ul

`<ul>` (unordered list) — список, где порядок не важен. Каждый пункт — `<li>` (list item):

```html preview
<ul>
  <li>Молоко</li>
  <li>Хлеб</li>
  <li>Сыр</li>
</ul>
```

Внутри `<ul>` могут быть **только** `<li>`. А вот внутри `<li>` — что угодно: ссылки, абзацы, картинки и даже другие списки.

## Нумерованный список ol

`<ol>` (ordered list) — порядок важен: шаги, рейтинг.

```html preview
<ol>
  <li>Разогреть сковороду</li>
  <li>Налить тесто</li>
  <li>Перевернуть блин</li>
</ol>

<ol start="5" reversed>
  <li>Пятое место</li>
  <li>Четвёртое</li>
</ol>
```

Атрибуты: `start` — с какого числа начать, `reversed` — обратный счёт, `type="A"` / `"i"` — буквы или римские цифры.

## Вложенные списки

Вложенный список ставится **внутрь** `<li>`, а не между ними:

```html preview
<ul>
  <li>Фронтенд
    <ul>
      <li>HTML</li>
      <li>CSS</li>
      <li>JavaScript</li>
    </ul>
  </li>
  <li>Бэкенд</li>
</ul>
```

> [!tip] Совет
> Навигация сайта — это тоже список ссылок: `<nav><ul><li><a>…</a></li></ul></nav>`. Маркеры потом убирают в CSS (`list-style: none`), а скринридер сообщит: «список, 5 элементов» — пользователю это полезно.

## Список описаний dl

`<dl>` — пары «термин — описание»: глоссарий, характеристики, FAQ.

```html preview
<dl>
  <dt>HTML</dt>
  <dd>Язык разметки — структура страницы.</dd>
  <dt>CSS</dt>
  <dd>Язык стилей — внешний вид.</dd>
</dl>
```

## Таблицы

Таблицы — для **табличных данных**: расписаний, сравнений, отчётов. Раньше таблицами верстали целые сайты — сейчас так делать нельзя, для раскладки есть Flexbox и Grid.

```html preview
<table>
  <caption>Расписание занятий</caption>
  <thead>
    <tr>
      <th scope="col">День</th>
      <th scope="col">Тема</th>
      <th scope="col">Часы</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Пн</th>
      <td>HTML</td>
      <td>2</td>
    </tr>
    <tr>
      <th scope="row">Ср</th>
      <td>CSS</td>
      <td>3</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row" colspan="2">Итого</th>
      <td>5</td>
    </tr>
  </tfoot>
</table>
```

| Тег | Что это |
|---|---|
| `<table>` | Таблица |
| `<caption>` | Подпись (название) таблицы |
| `<thead>`, `<tbody>`, `<tfoot>` | Шапка, тело, подвал |
| `<tr>` | Строка (table row) |
| `<th>` | Ячейка-заголовок. `scope="col"` — для столбца, `scope="row"` — для строки |
| `<td>` | Обычная ячейка (table data) |

Объединение ячеек: `colspan="2"` — ячейка шириной в два столбца, `rowspan="2"` — высотой в две строки.
