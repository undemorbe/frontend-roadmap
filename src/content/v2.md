**Директивы** — специальные атрибуты с префиксом `v-`. Они говорят Vue, как связать элемент с данными: показать или скрыть, повторить для каждого элемента массива, подставить атрибут, повесить обработчик.

## v-bind: атрибуты из данных

Интерполяция `{{ }}` работает только в тексте. Для атрибутов нужна директива `v-bind` или её сокращение — двоеточие:

```html
<img v-bind:src="photoUrl" v-bind:alt="photoAlt">
<img :src="photoUrl" :alt="photoAlt">   <!-- то же самое -->
<button :disabled="isLoading">Отправить</button>
<a :href="`/stations/${id}`">Станция</a>
```

Значение атрибута — JS-выражение. Если значение `null` или `undefined` (а для `disabled` — `false`), атрибут удаляется.

## Классы и стили

Для `class` и `style` у `v-bind` есть удобные формы — объект и массив:

```html
<!-- класс active добавится, если isActive истинно -->
<li :class="{ active: isActive, closed: station.closed }">...</li>

<!-- обычный class и :class объединяются -->
<div class="card" :class="[theme, { big: isBig }]">...</div>

<p :style="{ color: lineColor, fontSize: size + 'px' }">...</p>
```

## v-on: события

`v-on:click` или короче `@click`. Значение — имя функции или выражение:

```html
<button @click="count++">+1</button>
<button @click="remove(item.id)">Удалить</button>
<form @submit.prevent="save">...</form>      <!-- .prevent = preventDefault() -->
<input @keyup.enter="add">                    <!-- только по Enter -->
```

**Модификаторы** (`.prevent`, `.stop`, `.once`, `.enter`, `.esc`) избавляют от рутины вроде `event.preventDefault()`.

## v-if, v-else-if, v-else

Условный рендеринг: элемент **создаётся или удаляется** из DOM.

```html preview vue
<div id="app">
  <button @click="minutes = (minutes + 2) % 8">Время ожидания: {{ minutes }} мин</button>
  <p v-if="minutes === 0">🚇 Поезд на платформе</p>
  <p v-else-if="minutes < 3">Поезд прибывает</p>
  <p v-else>Ожидайте поезд</p>
</div>

<script>
  const { createApp, ref } = Vue
  createApp({
    setup() {
      const minutes = ref(0)
      return { minutes }
    },
  }).mount('#app')
</script>
```

## v-show

`v-show` тоже скрывает элемент, но иначе: элемент всегда в DOM, переключается только `display: none`.

| | `v-if` | `v-show` |
|---|---|---|
| Как скрывает | Удаляет элемент из DOM | `display: none` |
| Начальная стоимость | Дешевле, если сразу скрыто | Рендерит всегда |
| Переключение | Дороже (создание заново) | Дешевле |
| Когда использовать | Редко меняется | Часто переключается (вкладки, меню) |

## v-for: списки

```html preview vue
<div id="app">
  <ul>
    <li v-for="(station, index) in stations" :key="station.id"
        :style="{ color: station.closed ? '#999' : 'inherit' }">
      {{ index + 1 }}. {{ station.name }}
      <span v-if="station.closed">(закрыта)</span>
    </li>
  </ul>
</div>

<script>
  const { createApp, ref } = Vue
  createApp({
    setup() {
      const stations = ref([
        { id: 1, name: 'Теги' },
        { id: 2, name: 'Селекторы' },
        { id: 3, name: 'Flexbox', closed: true },
      ])
      return { stations }
    },
  }).mount('#app')
</script>
```

Атрибут **`:key`** обязателен: уникальный идентификатор помогает Vue понять, какой элемент изменился, добавился или удалился. Без него при сортировке и удалении возможны ошибки (например, состояние полей «переедет» к соседу). Не используйте `index` как ключ, если порядок может меняться.

`v-for` умеет перебирать и объект (`v-for="(value, key) in obj"`), и диапазон (`v-for="n in 5"`).

> [!warn] Осторожно
> Не ставьте `v-if` и `v-for` на один элемент: у `v-if` приоритет выше, и он не увидит переменную цикла. Отфильтруйте массив заранее (через `computed`, станция 4) или оберните в `<template v-for>`.

## template: группа без обёртки

Тег `<template>` позволяет применить директиву к нескольким элементам, не добавляя лишний `div` в разметку:

```html
<template v-if="user">
  <h2>{{ user.name }}</h2>
  <p>{{ user.email }}</p>
</template>
```

## v-html и v-text

`v-text` — то же, что интерполяция. `v-html` вставляет **HTML-разметку** — используйте только для доверенного содержимого: вставка пользовательского текста через `v-html` — прямой путь к XSS-уязвимости.
