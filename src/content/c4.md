Для браузера **каждый элемент — прямоугольник**. Даже круглая аватарка и буква в тексте. Как считаются размеры этих прямоугольников, описывает блочная модель (box model). Это фундамент всей раскладки.

## Четыре слоя коробки

```text
┌──────────── margin (внешний отступ) ────────────┐
│ ┌────────── border (рамка) ──────────────────┐  │
│ │ ┌──────── padding (внутренний отступ) ───┐ │  │
│ │ │                                        │ │  │
│ │ │          content (содержимое)          │ │  │
│ │ │                                        │ │  │
│ │ └────────────────────────────────────────┘ │  │
│ └────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────┘
```

- **content** — текст, картинка; его размер задают `width` и `height`;
- **padding** — отступ от содержимого до рамки. Фон элемента заливает и его;
- **border** — рамка;
- **margin** — отступ снаружи, расстояние до соседей. Всегда прозрачный.

```html preview
<div class="box">Содержимое</div>
<style>
  .box {
    width: 200px;
    padding: 20px;
    border: 6px solid #2167c9;
    margin: 30px;
    background: #ffe9a8;
  }
  body { background: repeating-linear-gradient(45deg, #fff 0 6px, #f0f0f0 6px 12px); margin: 0; }
</style>
```

Откройте DevTools → Elements → вкладка **Computed**: там нарисована схема блочной модели выбранного элемента с реальными числами.

## Сокращённая запись

```css
padding: 10px;              /* все четыре стороны */
padding: 10px 20px;         /* верх-низ | лево-право */
padding: 10px 20px 30px;    /* верх | лево-право | низ */
padding: 10px 20px 30px 40px; /* верх | право | низ | лево — по часовой стрелке */

margin-top: 8px;            /* отдельные стороны */
border: 2px solid red;      /* толщина стиль цвет */
border-bottom: 1px dashed #ccc;
border-radius: 12px;        /* скругление углов; 50% — круг */
```

Логические свойства учитывают направление письма и всё чаще используются: `margin-inline` (лево-право), `margin-block` (верх-низ), `padding-inline-start`.

## box-sizing: самая полезная строчка

По умолчанию (`content-box`) `width` задаёт ширину **только содержимого**. Padding и border **прибавляются**: блок `width: 200px; padding: 20px; border: 6px` на деле займёт 252px. Это неудобно.

С `box-sizing: border-box` ширина включает padding и border — блок будет ровно 200px:

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

Эта строчка есть почти в каждом проекте — добавляйте её первой.

## display: блочные и строчные

| `display` | Поведение |
|---|---|
| `block` | С новой строки, на всю ширину родителя, слушается `width`/`height` и всех отступов |
| `inline` | В строку с текстом. **Игнорирует** `width`, `height` и вертикальные `margin` |
| `inline-block` | В строку, но как коробка: слушается размеров и отступов |
| `none` | Элемент полностью убран со страницы |
| `flex`, `grid` | Включают современную раскладку детей (отдельные станции) |

```html preview
<p>Текст со <span class="i">строчным span</span> и <span class="ib">inline-block span</span> внутри.</p>
<style>
  .i, .ib { width: 150px; padding: 6px; margin: 12px; background: #c9ddff; }
  .ib { display: inline-block; background: #ffd36b; }
</style>
```

## Схлопывание отступов

Вертикальные `margin` соседних блочных элементов **не складываются, а схлопываются**: между абзацами с `margin: 20px 0` будет 20px, а не 40px. Побеждает больший. Горизонтальные отступы и отступы во flex/grid не схлопываются.

## Размеры: auto, min, max

- `width: auto` (по умолчанию для блоков) — занять всю доступную ширину;
- `max-width: 600px` — не шире, но может быть уже. Основа адаптивности;
- `min-height: 100vh` — минимум на высоту экрана;
- `margin: 0 auto` — классический способ отцентровать блок с заданной шириной по горизонтали.

```css
.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 16px;
}
```

## Переполнение: overflow

Если содержимое не влезает в заданные размеры, оно «вываливается». Свойство `overflow` решает, что делать:

- `visible` — по умолчанию, торчит наружу;
- `hidden` — обрезать;
- `auto` — полоса прокрутки, если нужно;
- `scroll` — прокрутка всегда.
