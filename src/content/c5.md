Большая часть веба — текст. Хорошая типографика и аккуратные цвета делают страницу удобной ещё до всяких картинок и анимаций.

## Шрифты

```css
body {
  font-family: "Onest", "Segoe UI", system-ui, sans-serif;
  font-size: 18px;
  font-weight: 400;      /* 100–900; 400 = normal, 700 = bold */
  font-style: normal;    /* или italic */
  line-height: 1.6;      /* межстрочный интервал — множитель без единиц */
}
```

`font-family` — это **список**: если первого шрифта нет, берётся следующий. В конце всегда пишут **родовое семейство**: `sans-serif` (без засечек), `serif` (с засечками), `monospace` (моноширинный), `system-ui` (системный шрифт ОС).

### Подключение своих шрифтов

Через Google Fonts:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Onest:wght@400;700&display=swap" rel="stylesheet">
```

Или из своих файлов через `@font-face`:

```css
@font-face {
  font-family: "MyFont";
  src: url("fonts/myfont.woff2") format("woff2");
  font-weight: 400;
  font-display: swap; /* показать текст системным шрифтом, пока грузится свой */
}
```

Формат **WOFF2** — самый лёгкий, используйте его. Вариативные шрифты (variable fonts) содержат все начертания в одном файле.

## Оформление текста

```css
text-align: center;          /* left | right | center | justify */
text-transform: uppercase;   /* ВСЕ ЗАГЛАВНЫЕ */
letter-spacing: 0.05em;      /* разрядка */
text-decoration: underline;  /* none — убрать подчёркивание ссылок */
text-indent: 2em;            /* красная строка */
white-space: nowrap;         /* запретить перенос */
text-overflow: ellipsis;     /* многоточие (вместе с overflow: hidden и nowrap) */
text-wrap: balance;          /* ровные строки в заголовках */
```

## Единицы измерения

| Единица | Относительно чего | Где использовать |
|---|---|---|
| `px` | Пиксели (абсолютная) | Рамки, тени, мелкие детали |
| `%` | Размер родителя | Ширина в раскладке |
| `em` | Размер шрифта **текущего** элемента | Отступы, которые растут вместе с текстом (кнопки) |
| `rem` | Размер шрифта **корня** (`html`, обычно 16px) | Размеры шрифтов, отступы — главная единица |
| `vw`, `vh` | 1% ширины/высоты окна | Полноэкранные блоки, «резиновые» заголовки |
| `ch` | Ширина символа «0» | Длина строки текста: `max-width: 65ch` |

> [!tip] Совет
> Задавайте размеры шрифтов в `rem`. Если пользователь увеличил базовый шрифт в настройках браузера (это делают люди с плохим зрением), вся страница аккуратно масштабируется. С `px` — нет.

Функция `clamp(min, ideal, max)` делает «резиновую» типографику без медиазапросов:

```css
h1 { font-size: clamp(2rem, 5vw, 4rem); } /* от 32px до 64px, между — 5% ширины окна */
```

## Цвет

Способы записать цвет:

```css
color: tomato;                    /* имя (их ~150) */
color: #ff6347;                   /* HEX: RRGGBB */
color: #f63;                      /* короткий HEX */
color: #ff634780;                 /* HEX с прозрачностью */
color: rgb(255 99 71);            /* красный, зелёный, синий 0–255 */
color: rgb(255 99 71 / 50%);      /* с прозрачностью */
color: hsl(9 100% 64%);           /* тон 0–360°, насыщенность, светлота */
color: oklch(70% 0.19 35);        /* современный: светлота, хрома, тон */
```

**HSL** удобен людям: чтобы сделать цвет темнее — уменьши светлоту. **OKLCH** — новый стандарт: одинаковая светлота действительно *выглядит* одинаково светлой для разных тонов, что важно для дизайн-систем.

`currentColor` — ключевое слово «текущий цвет текста». Удобно для рамок и SVG-иконок.

### Контраст

Текст должен быть читаемым: контраст основного текста к фону — не меньше **4.5 : 1** (требование WCAG AA). DevTools показывает коэффициент контраста при выборе цвета.

## Фон

```css
background-color: #f4f1e9;
background-image: url("pattern.png");
background-repeat: no-repeat;
background-position: center;
background-size: cover;         /* заполнить, обрезав лишнее */

background: linear-gradient(135deg, #2167c9, #2e9e6a);
background: radial-gradient(circle at top, #fff, #ddd);
```

```html preview

<div class="tile radial">radial-gradient</div>

  .radial { background: radial-gradient(circle at 30% 20%, #ffd36b, #e4402f); }
</style>
```

## Тени

```css
box-shadow: 0 4px 12px rgb(0 0 0 / 15%);   /* смещение-x смещение-y размытие цвет */
box-shadow: 4px 4px 0 #222;                /* жёсткая «бруталистская» тень */
text-shadow: 0 1px 2px rgb(0 0 0 / 30%);
```
