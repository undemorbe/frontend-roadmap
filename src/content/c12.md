Конечная линии CSS. Соберите **адаптивный лендинг** — одностраничный сайт курса или продукта. Здесь пригодится всё: переменные, Flexbox, Grid, адаптивность, переходы.

## Макет

```text
┌───────────────────────────────────────────┐
│ header: логотип ............ nav (flex)   │
├───────────────────────────────────────────┤
│ hero: крупный заголовок, текст, кнопка    │
├───────────────────────────────────────────┤
│ features: карточки преимуществ (grid)     │
│  [   ]  [   ]  [   ]                      │
├───────────────────────────────────────────┤
│ footer                                    │
└───────────────────────────────────────────┘
```

На телефоне карточки — в одну колонку, на широком экране — в три.

## Требования

1. **Токены**: в `:root` минимум 3 CSS-переменные (цвета/отступы) и они используются.
2. **Reset**: `box-sizing: border-box` для всех элементов.
3. **Шапка** — Flexbox, логотип и навигация по краям, по центру по вертикали.
4. **Hero** — заголовок с `clamp()`.
5. **Кнопка** — с `transition` и состоянием `:hover`.
6. **Преимущества** — Grid: 1 колонка на 400px, 3 колонки на 1000px.
7. **Контейнер** — содержимое не шире `1100px` и по центру.

> [!tip] Совет
> Начните с мобильной версии и «растягивайте» окно — так быстрее заметить, где ломается макет. Кнопка «Открыть в песочнице» в примерах уроков и раздел «Депо» помогут поэкспериментировать отдельно.

## Пример подхода к контейнеру

```css
.container {
  width: min(100% - 32px, 1100px);  /* отступы по 16px на телефоне */
  margin-inline: auto;
}
```
