**Реактивность** — сердце Vue. Это механизм, благодаря которому изменение данных автоматически обновляет интерфейс. На этой станции разберёмся, как она устроена и где её можно случайно «сломать».

## Как Vue узнаёт об изменениях

Обычная переменная — просто значение в памяти. Когда вы пишете `count++`, никто об этом не узнаёт. Vue оборачивает данные в **Proxy** (вспомните объекты из линии JS): при **чтении** значения Vue запоминает, кто его читал (например, шаблон), а при **записи** — оповещает всех читателей, что пора обновиться.

```js
// упрощённая идея
const state = new Proxy({ count: 0 }, {
  get(target, key) {
    track(target, key)    // запомнить: «шаблон читает count»
    return target[key]
  },
  set(target, key, value) {
    target[key] = value
    trigger(target, key)  // оповестить всех, кто читал count
    return true
  },
})
```

## ref

`ref()` подходит для **любых** значений: чисел, строк, массивов, объектов. Значение хранится в свойстве `.value`:

```js
const count = ref(0)
const user = ref({ name: 'Анна', stations: [] })

count.value++
user.value.name = 'Мария'            // объекты внутри ref тоже реактивны (глубоко)
user.value.stations.push('Теги')     // и массивы — push, splice и т. д. работают
user.value = { name: 'Новый' }       // можно заменить целиком
```

## reactive

`reactive()` делает реактивным **объект** — без `.value`:

```js
const state = reactive({
  count: 0,
  items: [],
})

state.count++
state.items.push('Новая')
```

Но у `reactive` есть ограничения:

```js
let state = reactive({ count: 0 })
state = reactive({ count: 1 })     // ❌ связь с шаблоном потеряна — заменили объект

const { count } = state            // ❌ count — обычное число, не реактивно
count++                            // интерфейс не обновится

reactive(5)                        // ❌ примитивы не поддерживаются
```

> [!tip] Совет
> Документация Vue рекомендует по умолчанию использовать `ref` — он работает с любыми значениями и его можно безопасно заменить целиком. `reactive` удобен для группы связанных полей (например, данные формы).

## Обновление DOM асинхронно

Vue не перерисовывает страницу сразу при каждом изменении — он **копит** изменения и применяет их пачкой в следующем «тике». Поэтому десять изменений подряд вызовут одну перерисовку. Если нужно что-то сделать с DOM **после** обновления, используйте `nextTick`:

```js
import { nextTick } from 'vue'

items.value.push(newItem)
await nextTick()
// здесь DOM уже содержит новый элемент — можно к нему прокрутить
```

## Демо: ref и reactive вместе

```html preview vue
<div id="app">
  <p>Поезд: {{ train.name }}, вагонов: {{ train.cars.length }}</p>
  <p>Пассажиров: {{ passengers }}</p>
  <button @click="addCar">Прицепить вагон</button>
  <button @click="board">Посадка (+10)</button>
  <button @click="rename">Переименовать</button>
</div>

<script>
  const { createApp, ref, reactive } = Vue
  createApp({
    setup() {
      const passengers = ref(0)
      const train = reactive({ name: 'Красная стрела', cars: [1, 2] })
      const addCar = () => train.cars.push(train.cars.length + 1)
      const board = () => (passengers.value += 10)
      const rename = () => (train.name = train.name === 'Красная стрела' ? 'Ласточка' : 'Красная стрела')
      return { passengers, train, addCar, board, rename }
    },
  }).mount('#app')
</script>
```

## Разворачивание ref

- В **шаблоне** ref верхнего уровня разворачивается автоматически: `{{ count }}`, а не `{{ count.value }}`.
- Ref внутри `reactive` тоже разворачивается: `state.count`, если `state = reactive({ count: ref(0) })`.
- А вот ref внутри **массива** или `Map` не разворачивается.

## readonly и toRefs

```js
const original = reactive({ count: 0 })
const copy = readonly(original)     // попытка изменить copy вызовет предупреждение

const state = reactive({ x: 0, y: 0 })
const { x, y } = toRefs(state)      // ✓ x и y — ref'ы, связанные с state
```
