Любое значение в JavaScript имеет **тип**. От типа зависит, что с ним можно делать: числа складывают, строки склеивают, у объектов есть свойства. JavaScript — язык с **динамической типизацией**: переменная может хранить значения разных типов в разное время.

## Восемь типов данных

| Тип | Примеры | Что это |
|---|---|---|
| `number` | `42`, `3.14`, `-7`, `Infinity`, `NaN` | Числа: целые и дробные |
| `bigint` | `9007199254740993n` | Очень большие целые |
| `string` | `'текст'`, `"текст"`, `` `шаблон ${x}` `` | Строки |
| `boolean` | `true`, `false` | Логический тип |
| `null` | `null` | «Пусто», значение намеренно отсутствует |
| `undefined` | `undefined` | «Не задано» — значение ещё не присвоено |
| `symbol` | `Symbol('id')` | Уникальный идентификатор |
| `object` | `{ name: 'Аня' }`, `[1, 2]` | Сложные структуры (массивы — тоже объекты) |

Первые семь — **примитивы** (простые значения). Объекты — ссылочный тип (подробнее на станции «Объекты»).

Оператор `typeof` возвращает тип строкой:

```js preview
console.log(typeof 42)          // number
console.log(typeof 'привет')    // string
console.log(typeof true)        // boolean
console.log(typeof undefined)   // undefined
console.log(typeof {})          // object
console.log(typeof [])          // object — массив это объект
console.log(typeof null)        // object — известная историческая ошибка языка
```

## Строки и шаблонные строки

Кавычки `'` и `"` равнозначны. Обратные кавычки `` ` `` создают **шаблонную строку**: в неё можно вставлять выражения через `${...}` и переносить строки.

```js
const name = 'Аня'
const age = 25
const msg = `Привет, ${name}! Через год тебе будет ${age + 1}.`
```

Полезное у строк: `str.length`, `str.toUpperCase()`, `str.includes('a')`, `str.trim()`, `str.slice(0, 3)`, `str.split(',')`, `str.replace('a', 'b')`, `str.startsWith('http')`.

## Числа и математика

```js
10 + 3   // 13
10 - 3   // 7
10 * 3   // 30
10 / 3   // 3.3333333333333335
10 % 3   // 1 — остаток от деления
2 ** 10  // 1024 — степень

0.1 + 0.2        // 0.30000000000000004 — особенность дробей в двоичной системе
Math.round(4.6)  // 5
Math.floor(4.6)  // 4
Math.max(1, 5, 3) // 5
Math.random()    // от 0 до 1
(12.345).toFixed(1) // '12.3' — строка!
```

`NaN` (Not a Number) — результат некорректной математики: `'abc' * 2`. Проверка — `Number.isNaN(x)`.

## Преобразование типов

Часто нужно превратить строку в число (значения из полей ввода — **всегда строки**!):

```js
Number('42')      // 42
Number('42px')    // NaN
parseInt('42px')  // 42 — читает число в начале строки
parseFloat('3.5кг') // 3.5
String(42)        // '42'
Boolean(0)        // false
```

JavaScript ещё и преобразует **неявно**, иногда неожиданно:

```js
'5' + 2   // '52' — плюс со строкой склеивает
'5' - 2   // 3   — минус приводит к числу
'5' * '2' // 10
```

**Ложные значения** (в логическом контексте становятся `false`): `false`, `0`, `''` (пустая строка), `null`, `undefined`, `NaN`. Всё остальное — истинное, включая `'0'`, `[]` и `{}`.

## Сравнение: == и ===

```js
5 === 5     // true
5 === '5'   // false — строгое: типы разные
5 == '5'    // true  — нестрогое: приводит типы
0 == false  // true
null == undefined // true
```

> [!tip] Совет
> Всегда используйте строгое сравнение `===` и `!==`. Нестрогое `==` полно сюрпризов. Единственное популярное исключение: `x == null` — проверка «x равен null или undefined».

## Логические операторы

```js
true && false  // false — И: true, если оба true
true || false  // true  — ИЛИ: true, если хотя бы один
!true          // false — НЕ
```

`&&` и `||` возвращают не `true/false`, а **одно из значений**:

```js
const name = userName || 'Гость'   // если userName ложное — 'Гость'
user && user.logout()              // вызвать, только если user есть
```

Современные операторы:

```js
const count = input ?? 0            // ?? — только если null или undefined (0 и '' сохраняются)
const city = user?.address?.city    // ?. — не упасть, если чего-то нет по пути
```
