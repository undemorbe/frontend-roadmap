Прежде чем писать код, разберёмся, что вообще происходит, когда вы открываете сайт. Эта станция — карта местности: кто с кем общается, что такое URL и HTTP, и почему фронтенд делится на три языка.

## Клиент и сервер

Интернет — это огромная сеть компьютеров. Когда вы открываете сайт, общаются двое:

- **клиент** — ваш браузер (Chrome, Firefox, Safari). Он *просит* страницу;
- **сервер** — компьютер где-то в дата-центре. Он *отдаёт* файлы: HTML, CSS, JavaScript, картинки, шрифты.

Фронтенд-разработчик пишет то, что **выполняется у клиента**, — в браузере пользователя. Бэкенд-разработчик пишет то, что работает на сервере: базы данных, авторизацию, API.

> [!info] Как это связано
> Всё, что вы изучите на линиях 1–3, браузер получает от сервера как обычные текстовые файлы. Линия 4 (Vite) научит собирать эти файлы из удобных исходников, а линия 5 (Vue) — строить из них целые приложения.

## Адрес страницы: URL

Каждый ресурс в вебе имеет адрес — **URL** (Uniform Resource Locator). Разберём его по частям:

```text
https://learn.javascript.ru:443/intro?lang=ru#start
└─┬──┘   └──────┬────────┘ └┬┘ └─┬─┘└───┬──┘└──┬┘
протокол      домен        порт путь  параметры якорь
```

| Часть | Пример | Зачем |
|---|---|---|
| Протокол | `https` | Как общаться. `s` — значит соединение зашифровано |
| Домен | `learn.javascript.ru` | Имя сервера. DNS превращает его в IP-адрес |
| Порт | `443` | «Номер двери» на сервере. Для https по умолчанию 443, его не пишут |
| Путь | `/intro` | Какой ресурс нужен |
| Параметры | `?lang=ru` | Дополнительные данные в формате `ключ=значение&ключ2=значение2` |
| Якорь (хэш) | `#start` | Место на странице. На сервер **не отправляется** |

## Что делает браузер

Когда вы нажимаете Enter в адресной строке:

1. **DNS-запрос.** Браузер узнаёт IP-адрес сервера по домену.
2. **HTTP-запрос.** Браузер отправляет серверу текстовое сообщение: «дай мне `/intro`».
3. **HTTP-ответ.** Сервер отвечает кодом статуса и содержимым — обычно HTML.
4. **Разбор HTML.** Браузер читает HTML сверху вниз и строит **DOM** — дерево объектов-элементов.
5. **Загрузка ресурсов.** Встретив `<link>`, `<img>`, `<script>`, браузер запрашивает их отдельно.
6. **Отрисовка.** Из DOM и CSS строится раскладка (layout), затем пиксели рисуются на экране (paint).

Запрос и ответ — это просто текст:

```http
GET /intro HTTP/1.1
Host: learn.javascript.ru
Accept: text/html
```

```http
HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8

<!doctype html>
<html>...
```

Коды статуса стоит знать «в лицо»: **200** — всё хорошо, **301/302** — переехало, **404** — не найдено, **500** — ошибка на сервере.

## Три языка фронтенда

Любая страница состоит из трёх слоёв. Удобно представлять их как дом:

| Язык | Роль | Аналогия |
|---|---|---|
| **HTML** | Структура и смысл: заголовки, абзацы, кнопки, формы | Стены и комнаты |
| **CSS** | Внешний вид: цвета, шрифты, расположение | Отделка и мебель |
| **JavaScript** | Поведение: реакция на действия, загрузка данных | Электрика и техника |

Посмотрите на все три слоя в одном примере. Нажмите на кнопку в результате:

```html preview
<h1>Привет, веб!</h1>
<p>Этот абзац — HTML. Цвет заголовка — CSS. Кнопка работает благодаря JavaScript.</p>
<button id="btn">Нажми меня</button>

<style>
  h1 { color: #2167c9; font-family: sans-serif; }
  button { padding: 8px 16px; font-size: 16px; }
</style>

<script>
  document.getElementById('btn').addEventListener('click', () => {
    document.querySelector('h1').textContent = 'Кнопка нажата!'
  })
</script>
```

> [!tip] Совет
> Слои можно (и нужно) разделять: HTML — в `.html`-файле, стили — в `.css`, скрипты — в `.js`. Так код проще читать и переиспользовать. В примере выше всё вместе только ради компактности.

## Инструменты разработчика

Для работы нужны всего две программы:

- **Браузер** с инструментами разработчика (DevTools). Откройте их клавишей <kbd>F12</kbd> или <kbd>⌘</kbd>+<kbd>⌥</kbd>+<kbd>I</kbd> на Mac. Самые нужные вкладки:
  - **Elements** — дерево DOM и стили любого элемента, можно править на лету;
  - **Console** — сообщения и ошибки JavaScript, можно выполнять код;
  - **Network** — все запросы страницы: что загрузилось, сколько весит, какой статус.
- **Редактор кода.** Стандарт индустрии — бесплатный [VS Code](https://code.visualstudio.com/). Полезные расширения: Prettier (форматирование), ESLint (проверка JS), Vue (Official) — для линии 5.

> [!task] Мини-задача
> Откройте DevTools прямо на этой странице, перейдите во вкладку Elements и найдите заголовок станции. Дважды кликните по тексту и поменяйте его. Ничего не сломается — изменения живут только до перезагрузки.
