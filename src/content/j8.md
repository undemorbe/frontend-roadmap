Пересадочная станция: здесь встречаются линии HTML и JavaScript. **DOM** (Document Object Model) — это ваш HTML, превращённый браузером в дерево объектов. Через DOM JavaScript читает и меняет страницу.

## Дерево документа

```html
<body>
  <h1>Заголовок</h1>
  <ul class="list">
    <li>Один</li>
    <li>Два</li>
  </ul>
</body>
```

Для браузера это дерево: `document` → `html` → `body` → `h1`, `ul` → `li`, `li`. Каждый тег — **узел-элемент** (объект с свойствами и методами), текст внутри — текстовый узел. Изменили объект — изменилась страница.

## Поиск элементов

```js
document.querySelector('.list')         // первый подходящий элемент или null
document.querySelectorAll('.list li')   // все подходящие (NodeList)
document.getElementById('app')          // по id

const list = document.querySelector('.list')
list.querySelector('li')                // поиск внутри элемента
```

Селекторы — те же, что в CSS! `querySelectorAll` возвращает NodeList: у него есть `forEach`, а для `map`/`filter` его превращают в массив: `[...nodeList]`.

Навигация по дереву: `el.parentElement`, `el.children`, `el.firstElementChild`, `el.nextElementSibling`, `el.closest('.card')` — ближайший предок, подходящий под селектор.

## Изменение содержимого

```js
const title = document.querySelector('h1')

title.textContent = 'Новый заголовок'   // только текст — безопасно
title.innerHTML = '<em>Курсив</em>'     // парсит HTML
```

> [!warn] Осторожно
> Никогда не вставляйте через `innerHTML` данные от пользователя: если там окажется `<img src=x onerror="...">`, выполнится чужой код (XSS-атака). Для текста — всегда `textContent`.

## Атрибуты, классы, стили

```js
const link = document.querySelector('a')
link.href = 'https://vuejs.org'               // свойство-атрибут
link.getAttribute('target')
link.setAttribute('target', '_blank')
link.removeAttribute('target')

const card = document.querySelector('.card')
card.classList.add('card--active')
card.classList.remove('card--hidden')
card.classList.toggle('open')                 // есть — убрать, нет — добавить
card.classList.contains('open')               // true / false

card.style.backgroundColor = 'gold'           // инлайновый стиль (camelCase)
card.dataset.id                               // атрибут data-id="..."

input.value                                   // значение поля (строка)
checkbox.checked                              // отмечен ли
button.disabled = true
```

> [!tip] Совет
> Предпочитайте менять **классы**, а не `style`. Внешний вид описан в CSS, а JS лишь переключает состояния — так проще поддерживать.

## Создание и удаление элементов

```js preview
const list = document.createElement('ul')
document.body.append(list)

const fruits = ['Яблоко', 'Груша', 'Слива']
for (const fruit of fruits) {
  const li = document.createElement('li')
  li.textContent = fruit
  li.className = 'fruit'
  list.append(li)
}

const first = list.querySelector('li')
first.style.fontWeight = 'bold'

const extra = document.createElement('li')
extra.textContent = 'Будет удалён'
list.append(extra)
extra.remove()

console.log('Элементов в списке:', list.children.length)
```

Методы вставки: `parent.append(el)` — в конец, `parent.prepend(el)` — в начало, `el.before(x)` / `el.after(x)` — рядом, `el.replaceWith(x)`, `el.remove()`.

Для разметки из шаблона удобен `<template>`: его содержимое не отображается, но его можно клонировать — `template.content.cloneNode(true)`.

## Отрисовка списка из данных

Типичная задача — отобразить массив данных. Простой способ:

```js
function renderList(items) {
  list.innerHTML = ''                 // очистить
  for (const item of items) {
    const li = document.createElement('li')
    li.textContent = item.title
    list.append(li)
  }
}
```

Каждый раз при изменении данных нужно не забыть вызвать `renderList` снова. Ручная синхронизация данных и DOM — именно та боль, которую решает Vue: вы меняете данные, а DOM обновляется сам. Это пересадка на станцию «Знакомство с Vue».
