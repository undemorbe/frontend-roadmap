Конечная жёлтой линии. Соберите классическое приложение — **список задач** — на чистом JavaScript. Именно на нём потом особенно хорошо видно, сколько ручной работы забирает на себя Vue.

## Архитектура: состояние → отрисовка

Главная идея, которая пригодится и во Vue:

```text
  действие пользователя ──► изменить состояние (массив todos)
                                   │
                                   ▼
                             render(todos) ──► DOM
                                   │
                                   ▼
                           сохранить в localStorage
```

Никогда не правьте DOM «точечно» в обработчиках. Обработчик меняет **данные** и вызывает `render()`. Так интерфейс всегда соответствует данным.

```js
let todos = load()

function update(newTodos) {
  todos = newTodos
  save(todos)
  render(todos)
}

// пример действия
function toggle(id) {
  update(todos.map((t) => (t.id === id ? { ...t, done: !t.done } : t)))
}
```

## Требования

1. Форма `.todo-form`: ввод текста и добавление по `submit`; пустые строки не добавляются, пробелы обрезаются.
2. Каждая задача — `<li class="todo">` с чекбоксом `.todo-toggle`, текстом `.todo-title` и кнопкой `.todo-delete`. Выполненная — с классом `todo--done`.
3. Переключение и удаление — через **делегирование** на `.todo-list`.
4. Счётчик `.todo-count` — «Осталось: N».
5. Фильтры: кнопки `[data-filter="all"]`, `[data-filter="active"]`, `[data-filter="done"]`.
6. Сохранение в `localStorage` под ключом `metro-todos` (массив объектов `{ id, title, done }`).

> [!tip] Совет
> Для `id` подойдёт `Date.now()` или `crypto.randomUUID()`. Для фильтра заведите вторую переменную состояния `filter` и учитывайте её в `render`.
