Flexbox — способ раскладки элементов **в одну линию**: строку или столбец. Меню, шапка, ряд карточек, центрирование чего угодно — всё это Flexbox. Это, пожалуй, самое используемое свойство современной вёрстки.

## Контейнер и элементы

Flexbox включается **на родителе**: `display: flex`. Его прямые дети становятся flex-элементами и выстраиваются в ряд.

```html preview
<div class="row">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
<style>
  .row { display: flex; gap: 10px; padding: 10px; border: 2px dashed #2167c9; }
  .item { padding: 16px 24px; background: #ffd36b; font: 700 18px sans-serif; }
</style>
```

## Две оси

У flex-контейнера есть **главная ось** (по ней идут элементы) и **поперечная** (перпендикулярно).

- `flex-direction: row` (по умолчанию) — главная ось горизонтальная, слева направо;
- `flex-direction: column` — главная ось вертикальная, сверху вниз;
- `row-reverse`, `column-reverse` — в обратном порядке.

Всё остальное зависит от осей: `justify-content` выравнивает **по главной**, `align-items` — **по поперечной**.

## Выравнивание

`justify-content` (по главной оси):

| Значение | Результат |
|---|---|
| `flex-start` | В начале (по умолчанию) |
| `center` | По центру |
| `flex-end` | В конце |
| `space-between` | Крайние — к краям, между остальными поровну |
| `space-around` / `space-evenly` | Равные промежутки и по краям |

`align-items` (по поперечной оси): `stretch` (растянуть, по умолчанию), `flex-start`, `center`, `flex-end`, `baseline`.

```html preview
<div class="nav">
  <b>Logo</b>
  <span>Меню · Цены · Контакты</span>
  <button>Войти</button>
</div>
<div class="center">Идеальный центр</div>
<style>
  body { font-family: sans-serif; }
  .nav { display: flex; justify-content: space-between; align-items: center; padding: 10px 14px; background: #eef3fb; border-radius: 10px; }
  .center { display: flex; justify-content: center; align-items: center; height: 100px; margin-top: 10px; background: #ffe9a8; border-radius: 10px; }
</style>
```

> [!tip] Совет
> Центрирование по обеим осям — три строчки: `display: flex; justify-content: center; align-items: center;`. Или ещё короче на Grid: `display: grid; place-items: center;`.

## gap — промежутки

`gap: 16px` задаёт расстояние **между** элементами, без лишнего отступа по краям. Больше не нужно писать `margin-right` всем, кроме последнего. `row-gap` и `column-gap` — отдельно по направлениям.

## Перенос: flex-wrap

По умолчанию элементы ужимаются, чтобы влезть в одну строку. `flex-wrap: wrap` разрешает перенос на новые строки — так делают «резиновые» ряды карточек.

## Гибкость элементов: flex-grow, flex-shrink, flex-basis

Эти свойства задаются **элементам**:

- `flex-grow` — какую долю свободного места забрать (0 — не расти);
- `flex-shrink` — насколько сжиматься при нехватке места (0 — не сжиматься);
- `flex-basis` — исходный размер до распределения (`auto`, `200px`, `30%`).

Обычно пишут сокращением `flex`:

```css
.sidebar { flex: 0 0 250px; } /* ровно 250px: не растёт, не сжимается */
.content { flex: 1; }         /* занимает всё оставшееся место */
.card    { flex: 1 1 220px; } /* от 220px, растягивается, переносится вместе с wrap */
```

```html preview
<div class="layout">
  <aside>Сайдбар 150px</aside>
  <main>Контент flex: 1 — растягивается</main>
</div>
<style>
  .layout { display: flex; gap: 10px; font-family: sans-serif; }
  aside { flex: 0 0 150px; background: #c9ddff; padding: 12px; }
  main { flex: 1; background: #ffe9a8; padding: 12px; }
</style>
```

## Отдельные элементы

- `align-self` — переопределить `align-items` для одного элемента;
- `order` — порядок отображения (не меняет порядок в HTML, осторожно с доступностью);
- `margin-left: auto` — «оттолкнуть» элемент и всё, что после него, к правому краю. Частый приём в навигации.
