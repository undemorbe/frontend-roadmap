Программы принимают решения и повторяют действия. Для этого есть **условия** (если — то) и **циклы** (повторяй, пока).

## if / else

```js
const hour = 14

if (hour < 12) {
  console.log('Доброе утро')
} else if (hour < 18) {
  console.log('Добрый день')
} else {
  console.log('Добрый вечер')
}
```

Условие в скобках приводится к логическому типу: `if (items.length)` сработает, если массив не пуст (вспомните ложные значения).

## Тернарный оператор

Короткая форма «если — то — иначе» **для значения**:

```js
const access = age >= 18 ? 'разрешён' : 'запрещён'
const label = count === 1 ? 'товар' : 'товаров'
```

Используйте его для выбора значения, а не для действий. Вложенные тернарники быстро становятся нечитаемыми.

## switch

Сравнивает значение с несколькими вариантами (строго, через `===`):

```js
switch (status) {
  case 'new':
    console.log('Новый заказ')
    break
  case 'paid':
  case 'shipped':
    console.log('В работе')
    break
  default:
    console.log('Неизвестный статус')
}
```

Не забывайте `break`: без него выполнение «провалится» в следующий `case`.

## Циклы while и for

```js
let i = 0
while (i < 3) {        // пока условие истинно
  console.log(i)
  i++
}

for (let i = 0; i < 3; i++) {  // начало; условие; шаг
  console.log(i)               // 0, 1, 2
}
```

`for` — когда известно число повторов. `while` — когда повторяем «пока что-то не случится».

```js preview
for (let i = 1; i <= 5; i++) {
  const stars = '★'.repeat(i)
  console.log(stars)
}
```

## Перебор коллекций: for...of

Для массивов и строк удобнее `for...of` — не нужен счётчик:

```js
const lines = ['HTML', 'CSS', 'JS']
for (const line of lines) {
  console.log(line)
}
```

Для ключей объекта есть `for...in`, но чаще используют `Object.keys(obj)` / `Object.entries(obj)` (станция «Объекты»). А у массивов есть методы `forEach`, `map`, `filter` (станция «Массивы»).

## break и continue

```js
for (const n of [3, 8, -1, 5]) {
  if (n < 0) break       // прервать цикл полностью
  if (n % 2 === 0) continue // пропустить итерацию, перейти к следующей
  console.log(n)         // 3
}
```

> [!warn] Осторожно
> Бесконечный цикл (`while (true)` без `break`, забытый `i++`) «вешает» вкладку. В песочнице поможет перезагрузка страницы.
