Конечная станция зелёной линии — и всего маршрута. Соберём всё, что знаем о Vue, в одном приложении: **трекер привычек**. Здесь встретятся SFC, props и события, `v-model`, `computed`, Pinia и сохранение в `localStorage`.

## Что строим

Приложение «Привычки»:

- форма добавления привычки (название, без пустых строк и дублей);
- список привычек: отметка «сделано сегодня», удаление;
- счётчик прогресса «Выполнено: X из Y» и полоска прогресса;
- фильтр: все / в процессе / выполненные;
- пустое состояние, когда привычек нет;
- данные переживают перезагрузку страницы (`localStorage`).

## Архитектура

```text
main.js                  ← createApp + Pinia
App.vue                  ← каркас: заголовок, прогресс, фильтр, список
stores/habits.js         ← состояние и вся логика
components/
├── HabitForm.vue        ← форма добавления (свой v-model не нужен — вызывает action)
└── HabitItem.vue        ← одна привычка: props + события toggle/remove
```

Принцип: **store отвечает за данные и правила** (что можно добавить, как фильтровать), **компоненты — за отображение** и пересылку действий пользователя. Тогда логику легко тестировать, а компоненты остаются простыми.

> [!tip] Совет
> `watch` можно использовать прямо внутри setup-store — это удобный способ синхронизировать состояние с `localStorage`, как composable `useStorage` со станции 9.

## Компоненты

`HabitItem.vue` ничего не знает о store — он получает `name` и `done` через props и сообщает о действиях событиями. Такой компонент легко переиспользовать и проверять:

```vue
<script setup>
defineProps({ name: String, done: Boolean })
defineEmits(['toggle', 'remove'])
</script>

<template>
  <li class="habit" :class="{ done }">
    <label>
      <input type="checkbox" class="check" :checked="done" @change="$emit('toggle')">
      {{ name }}
    </label>
    <button class="remove" @click="$emit('remove')" aria-label="Удалить">✕</button>
  </li>
</template>
```

## Доступность

- у поля ввода есть `<label>` (можно визуально скрытый);
- кнопки-иконки получают `aria-label`;
- активный фильтр помечается `aria-pressed="true"`;
- полоска прогресса — элемент `<progress>` с текстом рядом.
